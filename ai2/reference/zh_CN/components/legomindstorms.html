EV3颜色传感器（Ev3ColorSensor）

该组件为 LEGO MINDSTORMS EV3 机器人上的颜色传感器提供高层接口。

属性

AboveRangeEventEnabled
指定当光线强度高于 TopOfRange 时是否触发 AboveRange 事件。
BelowRangeEventEnabled
指定当光线强度低于 BottomOfRange 时是否触发 BelowRange 事件。
BluetoothClient
指定用于通信的 BluetoothClient 组件。必须在设计视图中设置。
BottomOfRange
指定 BelowRange、WithinRange 和 AboveRange 事件所用范围的下限。
ColorChangedEventEnabled
指定当 DetectColor 属性设为 True 且检测到的颜色发生变化时，是否触发 ColorChanged 事件
Mode
传感器当前的工作模式，取值为以下之一： Reflected：检测当前光线强度，其中包括传感器反射回来的光。 Ambient：检测当前光线强度，其中不包括传感器反射回来的光。 Color：检测传感器所指向的颜色。
SensorPort
指定传感器所连接的传感器端口。必须在设计视图中设置。
TopOfRange
指定 BelowRange、WithinRange 和 AboveRange 事件所用范围的上限。
WithinRangeEventEnabled
指定当光线强度介于 BottomOfRange 和 TopOfRange 之间时是否触发 WithinRange 事件。

事件

AboveRange()
光线强度已超出范围上限。
BelowRange()
光线强度已低于范围下限。
ColorChanged(colorCode,colorName)
当检测到的颜色发生变化时调用。
WithinRange()
光线强度已进入范围之内。

方法

GetColorCode()
返回检测到的颜色的颜色代码。
GetColorName()
返回检测到的颜色的名称。
GetLightLevel()
返回以百分比表示的光线强度。

NXT颜色传感器（NxtColorSensor）

该组件为 LEGO MINDSTORMS NXT 机器人上的颜色传感器提供高层接口。

属性

AboveRangeEventEnabled
指定当 DetectColor 属性设为 False 且光线强度高于 TopOfRange 时是否触发 AboveRange 事件。
BelowRangeEventEnabled
指定当 DetectColor 属性设为 False 且光线强度低于 BottomOfRange 时是否触发 BelowRange 事件。
BluetoothClient
指定用于通信的 BluetoothClient 组件。必须在设计视图中设置。
BottomOfRange
指定 BelowRange、WithinRange 和 AboveRange 事件所用范围的下限。
ColorChangedEventEnabled
指定当 DetectColor 属性设为 True 且检测到的颜色发生变化时，是否触发 ColorChanged 事件
DetectColor
指定传感器是检测颜色还是检测光线。True 表示传感器检测颜色；False 表示传感器检测光线。
GenerateColor
指定传感器应发出的颜色。只有 None、Red、Green、Blue 是有效值。当 DetectColor 属性设为 True 时，传感器不会发出颜色。
SensorPort
指定传感器所连接的传感器端口。必须在设计视图中设置。
TopOfRange
指定 BelowRange、WithinRange 和 AboveRange 事件所用范围的上限。
WithinRangeEventEnabled
指定当 DetectColor 属性设为 False 且光线强度介于 BottomOfRange 和 TopOfRange 之间时是否触发 WithinRange 事件。

事件

AboveRange()
光线强度已超出范围上限。如果 DetectColor 属性设为 True，或 AboveRangeEventEnabled 属性设为 False，则不会发生 AboveRange 事件。
BelowRange()
光线强度已低于范围下限。如果 DetectColor 属性设为 True，或 BelowRangeEventEnabled 属性设为 False，则不会发生 BelowRange 事件。
ColorChanged(color)
检测到的颜色已发生变化。如果 DetectColor 属性设为 False，或 ColorChangedEventEnabled 属性设为 False，则不会发生 ColorChanged 事件。
WithinRange()
光线强度已进入范围之内。如果 DetectColor 属性设为 True，或 WithinRangeEventEnabled 属性设为 False，则不会发生 WithinRange 事件。

方法

GetColor()
返回当前检测到的颜色；如果无法读取颜色，或 DetectColor 属性设为 False，则返回颜色 None。
GetLightLevel()
返回当前光线强度，取值为 0 到 1023 之间；如果无法读取光线强度，或 DetectColor 属性设为 True，则返回 -1。

向机器人上的邮箱（1-10）写入一条消息。
PlaySoundFile(fileName)
在机器人上播放声音文件。
PlayTone(frequencyHz,durationMs)
让机器人播放一个音调。
ResetInputScaledValue(sensorPortLetter)

ResetMotorPosition(motorPortLetter,relative)

SetBrickName(name)

SetInputMode(sensorPortLetter,sensorType,sensorMode)

SetOutputState(motorPortLetter,power,mode,regulationMode,turnRatio,runState,tachoLimit)

NXT电机驱动器（NxtDrive）

该组件为 LEGO MINDSTORMS NXT 机器人提供高层接口，其中的函数可以让机器人移动和转向。

属性

BluetoothClient
指定用于通信的 BluetoothClient 组件。必须在设计视图中设置。
DriveMotors
指定用于驱动的电机端口。
StopBeforeDisconnect
指定断开连接前是否停止驱动电机。
WheelDiameter
返回用于驱动的车轮直径。

事件

无

方法

MoveBackward(power,distance)
以指定的最大功率百分比，通过让两个驱动电机反向转动，使机器人后退指定距离。
MoveBackwardIndefinitely(power)
以指定的最大功率百分比，通过让两个驱动电机反向转动，使机器人持续后退。
MoveForward(power,distance)
以指定的最大功率百分比，通过让两个驱动电机正向转动，使机器人前进指定距离。
MoveForwardIndefinitely(power)
以指定的最大功率百分比，通过让两个驱动电机正向转动，使机器人持续前进。
Stop()
停止机器人的驱动电机。
TurnClockwiseIndefinitely(power)
以指定的最大功率百分比，通过让左驱动电机正向转动、右驱动电机反向转动，使机器人持续顺时针转向。
TurnCounterClockwiseIndefinitely(power)
以指定的最大功率百分比，通过让右驱动电机正向转动、左驱动电机反向转动，使机器人持续逆时针转向。

指定当接触传感器被按下时是否触发 Pressed 事件。
ReleasedEventEnabled
指定当接触传感器被松开时是否触发 Released 事件。
SensorPort
指定传感器所连接的传感器端口。必须在设计视图中设置。

事件

Pressed()
接触传感器已被按下。
Released()
接触传感器已被松开。

方法

IsPressed()
如果接触传感器被按下，则返回 true。

NXT超声波传感器（NxtUltrasonicSensor）

该组件为 LEGO MINDSTORMS NXT 机器人上的超声波传感器提供高层接口。

属性

AboveRangeEventEnabled
指定当距离超过 TopOfRange 时是否触发 AboveRange 事件。
BelowRangeEventEnabled
指定当距离低于 BottomOfRange 时是否触发 BelowRange 事件。
BluetoothClient
指定用于通信的 BluetoothClient 组件。必须在设计视图中设置。
BottomOfRange
指定 BelowRange、WithinRange 和 AboveRange 事件所用范围的下限。
SensorPort
指定传感器所连接的传感器端口。必须在设计视图中设置。
TopOfRange
指定 BelowRange、WithinRange 和 AboveRange 事件所用范围的上限。
WithinRangeEventEnabled
指定当距离介于 BottomOfRange 和 TopOfRange 之间时是否触发 WithinRange 事件。

事件

AboveRange()
距离已超出范围上限。
BelowRange()
距离已低于范围下限。
WithinRange()
距离已进入范围之内。

方法

GetDistance()
返回当前距离（以厘米为单位），取值为 0 到 254 之间；如果无法读取距离，则返回 -1。
