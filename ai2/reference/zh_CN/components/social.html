联系人选框（ContactPicker）

一个按钮，点击后会显示联系人列表供选择。用户做出选择后，以下属性将被设为 所选联系人的相关信息：

  • ContactName：联系人的姓名
  • EmailAddress：联系人的主要电子邮件地址
  • EmailAddressList：联系人的电子邮件地址列表
  • ContactUri：联系人在设备上的 URI
  • PhoneNumber：联系人的主要电话号码（在较新的 Android 版本上）
  • PhoneNumberList：联系人的电话号码列表（在较新的 Android 版本上）
  • Picture：包含联系人图像的文件名，可用作图像（Image）或图像精灵（ImageSprite）组件的图片属性值。

其他属性会影响按钮的外观（TextAlignment、 BackgroundColor 等）以及它是否可以被点击（Enabled）。

ContactPicker 组件可能并非在所有手机上都能正常工作。例如，在系统 3.0 之前的 Android 系统上，它无法选取电话号码，而且电子邮件地址列表只包含一个电子邮件地址。

属性

BackgroundColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定 ContactPicker 的背景色。 如果设置了 Image，则在移除该 Image 之前看不到颜色的变化。
ContactName
返回所选联系人的全名；如果姓名不可用，则返回空字符串。
ContactUri
返回一个 URI，指定联系人在设备上的位置。
EmailAddress
返回所选联系人的主要电子邮件地址；如果电子邮件 地址不可用，则返回空字符串。
EmailAddressList
返回与所选联系人关联的电子邮件地址列表。
Enabled
指定 ContactPicker 是否处于活动状态且可点击。
FontBold
指定 ContactPicker 的文本是否使用粗体。 有些字体不支持粗体。
FontItalic
指定 ContactPicker 的文本是否使用斜体。 有些字体不支持斜体。
FontSize
指定 ContactPicker 的文本字号，以 sp（缩放无关像素）为单位。

以 default、serif、sans serif、monospace 或自定义字体指定 ContactPicker 的文本字体。要添加自定义字体， 请将一个 .ttf 文件上传到项目的媒体资源中。

以 Screen 的 Height 的百分比形式 指定 ContactPicker 的垂直高度。
Image
指定 ContactPicker 图像的路径。如果同时指定了 Image 和 BackgroundColor，则只有 Image 可见。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
PhoneNumber
返回与所选联系人关联的主要电话号码；如果 该联系人没有关联电话号码，则返回空字符串。
PhoneNumberList
返回与所选联系人关联的电话号码列表。
Picture
返回所选联系人的图片 URI，可用于 获取联系人的照片及其他字段。
Shape
指定 ContactPicker 的形状。本属性的有效取值为 0（默认）、 1（圆角）、2（矩形）和 3（椭圆）。若使用了 Image，则 Shape 不可见。
ShowFeedback
指定当按下带有指定 Image 的 ContactPicker 时是否显示视觉反馈。
Text

TextAlignment
指定 ContactPicker 文本的对齐方式。有效取值为： 0（正常；例如，当文字从左到右书写时为左对齐）、 1（居中），或 2（相反；例如，当文字从左到右书写时为右对齐）。

以 Screen 的 Width 的百分比形式 指定 ContactPicker 的水平宽度。

邮箱选框（EmailPicker）

EmailPicker 是一种文本框。如果用户开始输入联系人的姓名或电子邮件地址， 手机将显示一个下拉菜单，列出可补全输入的选项。如果联系人很多，下拉菜单可能需要几秒钟才会出现， 并且在计算匹配项的过程中会显示中间结果。

文本框的初始内容以及用户输入后的内容都保存在 Text 属性中。如果 Text 属性初始为空，则 Hint 属性的内容将作为提示以浅色显示在文本框中，提示用户输入。

其他属性会影响文本框的外观（TextAlignment、 BackgroundColor 等）以及它是否可以使用（Enabled）。

这样的文本框通常与 Button 组件配合使用， 当文本输入完成后，由用户点击按钮。

属性

BackgroundColor
EmailPicker 的背景色。您可以按名称在设计视图或 编程视图中选择颜色。默认背景色为 'default'（带阴影的 3-D 外观）。
Enabled
若已设置，用户可以在 EmailPicker 中输入文本。
FontBold
指定 EmailPicker 的文本是否使用粗体。 有些字体不支持粗体。
FontItalic
指定 EmailPicker 的文本是否使用斜体。 有些字体不支持斜体。
FontSize
指定 EmailPicker 的文本字号，以 sp（缩放无关像素）为单位。
FontTypeface
EmailPicker 的文本字体。有效取值为 0（默认）、1（serif）、2（sans serif）或 3（monospace）。
Height
指定 EmailPicker 的垂直高度，以像素为单位。
HeightPercent
以 Screen 的 Height 的百分比形式 指定 EmailPicker 的垂直高度。
Hint
EmailPicker 向用户显示的提示。
HintColor
指定 EmailPicker 提示文字的颜色。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Text
EmailPicker 中的文本，可由程序员在设计视图或编程视图中设置， 也可由用户输入（除非 Enabled 属性为 false）。
TextAlignment
指定 EmailPicker 文本的对齐方式。有效取值为： 0（正常；例如，当文字从左到右书写时为左对齐）、 1（居中），或 2（相反；例如，当文字从左到右书写时为右对齐）。
TextColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定 EmailPicker 的文本颜色。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 EmailPicker 是否在屏幕上可见。若 EmailPicker 正在显示，值为 true； 若已隐藏，值为 false。
Width
指定 EmailPicker 的水平宽度，以像素为单位。
WidthPercent
以 Screen 的 Width 的百分比形式 指定 EmailPicker 的水平宽度。

事件

GotFocus()
当 EmailPicker 被选中以进行输入时（例如 由用户触摸它）引发的事件。
LostFocus()
当 EmailPicker 不再被选中以进行输入时（例如 用户触摸了另一个文本框）引发的事件。
TextChanged()
当 EmailPicker 的文本发生变化时引发的事件，无论是用户还是程序造成的。

方法

MoveCursorTo(position)
将 EmailPicker 的光标重新定位到给定（从 1 开始计数）位置处的字符之前。如果给定位置大于 EmailPicker 的长度，光标将移到文本末尾；如果给定位置小于或等于 1，光标将移到开头。
MoveCursorToEnd()
将光标重新定位到 EmailPicker 文本的末尾。
MoveCursorToStart()
将光标重新定位到 EmailPicker 文本的开头。
RequestFocus()
请求将焦点给予当前的 EmailPicker。

电话拨号器（PhoneCall）

一种非可视组件，用于拨打 PhoneNumber 属性中指定的号码， 该属性可以在设计视图或编程视图中设置。 该组件有一个 MakePhoneCall 方法，使程序能够发起电话呼叫。 您也可以使用 MakePhoneCallDirect 在不与用户 交互的情况下直接发起电话呼叫。但是，使用该块的应用如果提交 到 Play 商店，可能需要 Google 进一步审核，因此建议改用 MakePhoneCall。

该组件通常与 ContactPicker 组件配合使用，后者让用户 从手机上存储的联系人中进行选择，并将 PhoneNumber 属性设为 ContactPicker 的 PhoneNumber 属性。

要直接指定电话号码（例如 650-555-1212），请将 PhoneNumber 属性设为一个包含指定数字的文本（例如“6505551212”）。可以包含连字符、点和括号 （例如“(650)-555-1212”），但它们会被忽略；不可以包含空格。

属性

PhoneNumber
指定要拨打的电话号码。

事件

IncomingCallAnswered(phoneNumber)
表示来电已被接听的事件。phoneNumber 是 来电的电话号码。
PhoneCallEnded(status,phoneNumber)
表示电话呼叫已结束的事件。status 可以是以下任意值：
  • 1：来电未接或被拒接
  • 2：来电已接听并挂断
  • 3：去电已挂断。
PhoneCallStarted(status,phoneNumber)
表示电话呼叫已开始的事件。status 可以是以下任意值：
  • 1：来电正在响铃
  • 2：去电正在拨号

方法

MakePhoneCall()
启动默认拨号应用，并设置为使用 PhoneNumber 属性中的号码发起电话呼叫。
MakePhoneCallDirect()
使用 PhoneNumber 属性中的号码直接发起电话呼叫， 绕过用户交互来开始呼叫。大多数应用应改用 MakePhoneCall，它不需要任何权限。

信息分享器（Sharing）

信息分享器是一个非可视组件，用于在您的应用与设备上安装的其他应用之间分享文件和/或消息。 该组件将显示能够处理所提供信息的已安装应用列表，并允许用户选择其中一个来分享内容， 例如邮件应用、社交网络应用、短信应用等。

文件路径可以直接取自其他组件，例如 Camera 或 ImagePicker，但也可以 直接指定以从存储中读取。默认行为是分享与您的应用关联的私有 数据目录中的文件。如果文件路径以斜杠（/）开头，则分享相对于 / 的文件。

请注意，不同设备对存储的处理方式不同，因此，例如，如果您在文件夹 Appinventor/assets 中有一个 名为 arrow.gif 的文件，可以尝试以下几种写法：

  • "file:///sdcard/Appinventor/assets/arrow.gif"；或
  • "/storage/Appinventor/assets/arrow.gif"

短信收发器（Texting）

一种组件，当调用 SendMessage 方法时，它会启动设备首选的 短信应用，将 SendMessage 属性中指定的文本消息 发送到 PhoneNumber 属性中指定的电话号码。您也可以改为 调用 SendMessageDirect 在不与用户交互的情况下发送文本 消息，但这会给最终应用添加危险权限。

如果 ReceivingEnabled 属性设为 1，将不会接收消息。如果 ReceivingEnabled 设为 2，只有在应用运行时才会接收消息。最后，如果 ReceivingEnabled 设为 3， 应用运行时可以接收消息，而当应用未运行时，消息将进入队列， 并向用户显示一条通知。

当消息到达时，会引发 MessageReceived 事件， 并提供发送方号码和消息。

包含该组件的应用即使在后台运行时（即未显示在屏幕上时）也能接收消息，更有甚者， 只要该应用已安装在手机上，即使应用未运行也能接收。如果手机在应用不处于 前台时收到文本消息，手机会在通知栏中显示一条通知。选择该 通知将调出该应用。作为应用开发者，您很可能希望让用户能够 控制 ReceivingEnabled，以便他们可以让手机忽略文本消息。

如果 GoogleVoiceEnabled 属性为 true，则可以使用 Google Voice 通过 WiFi 发送消息。该选项要求用户拥有 Google Voice 账户，并且手机上安装了移动版 Voice 应用。Google Voice 选项仅在支持 Android 2.0（Eclair）或更高版本的手机上可用。遗憾的是，由于 Google Voice 应用引入的变更，接收功能已无法在 Google Voice 中使用。

要指定电话号码（例如 650-555-1212），请将 PhoneNumber 属性设为一个文本字符串， 其中包含指定的数字（例如 6505551212）。可以包含连字符、点和括号 （例如 (650)-555-1212），但它们会被忽略；不可以包含空格。

应用指定电话号码的另一种方式是加入 PhoneNumberPicker 组件，它让用户可以从手机联系人中存储的电话号码里选择一个。

属性

GoogleVoiceEnabled
如果该属性为 true，则 SendMessage 将尝试通过 WiFi 使用 Google Voice 发送消息。
Message
调用 SendMessage 方法时将发送的消息。 标准 SMS 消息的最大长度通常为 170。对于使用变音符号的语言， 可能会更短。
PhoneNumber
调用 SendMessage 方法时消息将发送到的号码。 该号码是包含指定数字的文本字符串（例如 6505551212）。可以包含连字符、点、 和括号（例如 (650)-555-1212），但它们会被忽略；不应 包含空格。如果以逗号分隔，可以包含多个号码。
ReceivingEnabled
如果设为 1（OFF），将不会接收任何消息。如果设为 2（FOREGROUND）或 3（ALWAYS）， 组件在运行时将响应消息。在 2（FOREGROUND）的情况下，应用 未运行时收到的消息将被丢弃。在 3（ALWAYS）的情况下，应用 未运行时收到的消息将显示一条通知。选择该通知 将调出应用并发出 MessageReceived 事件信号。应用 休眠时收到的消息将进入队列，因此当应用唤醒时可能会出现多个 MessageReceived 事件。作为应用 开发者，让用户能够控制该属性是个好主意，这样 当您的应用已安装时，他们可以让手机忽略文本消息。

事件

MessageReceived(number,messageText)
当手机收到文本消息时引发的事件。使用该块会添加 危险权限， 如果您的应用提交到 Google Play 商店，将需要额外审批。

方法

SendMessage()
启动手机的默认短信应用，并预填好消息和电话号码。
SendMessageDirect()
发送文本消息。使用该块会添加 危险权限， 如果您的应用提交到 Google Play 商店，将需要额外审批。
