ListView 布局

ListView 组件支持两种定义元素的方式：ElementsFromString 与 ListViewLayout。

ElementsFromString 是旧方式，只支持由单个字符串组成的元素。

ListViewLayout 与 ListData 配合使用，可以实现更复杂的元素布局，元素可以由多个字符串和一个可选图像组成。

ElementsFromString

这是用逗号分隔的字符串来描述 ListView 元素的旧方式，只支持由单个字符串组成的元素。

示例：Main Text 1, Main Text 2, Main Text 3

ListViewLayout 与 ListData

从 App Inventor蔻丁工坊 的 nb187 版本开始，ListView 支持高级布局选项。

在 ListViewLayout 属性中可以从一组选项里选择布局，然后在设计视图中用 ListData 属性定义元素。

ListData 属性编辑器是一个弹出窗口，用户可以在其中定义主文本（Main Text）、副文本（Detail Text）和图像（Image），具体取决于所选布局。图像从上传到媒体中的图像列表里选择。
