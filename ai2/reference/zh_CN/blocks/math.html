在内置块中找不到您要用的数学块？

有些数学块带有下拉菜单，也就是说它们可以转换成不同的块。下面列出每个下拉菜单中包含的块。

=, ≠, >, ≥, <, ≤

最小值、最大值

平方根、绝对值、-、对数值、e的乘方、四舍五入、就高取整、就低取整

模数、余数、商数

正弦、余弦、正切、反正弦、反余弦、反正切

由弧度转角度、由角度转弧度

基础数字块

可用作任意正数或负数。点击块中的“0”即可修改这个数字。

该块支持普通的十进制数（例如：2、12、2.12），也支持其他进制的类 C 前缀写法。它支持：

  • 二进制（Base-2）数，如 0b10（十进制 2）
  • 八进制（Base-8）数，如 0o14（十进制 12）
  • 十六进制（Base-16）数，如 0xd4（十进制 212）

进制数字块

表示一个十进制数。点击“0”即可修改这个数字。

点击下拉菜单，可以用其他进制（也称为基数）输入数字。该数字随后会被“转换”为十进制（也称为 Base-10）。

下拉菜单支持以下输入格式：十进制（Base-10）、二进制（Base-2）、八进制（Base-8）和十六进制（Base-16）。

十进制模式允许输入任意正数或负数（例如 2、-12、2.12）。其他模式只允许输入整数（即任意正数或零）。

= {#=}

判断两个数字是否相等，返回“真”或“假”。

≠ {#not=}

判断两个数字是否不相等，返回“真”或“假”。

>

判断第一个数字是否大于第二个数字，返回“真”或“假”。

≥

判断第一个数字是否大于或等于第二个数字，返回“真”或“假”。

<

判断第一个数字是否小于第二个数字，返回“真”或“假”。

≤

判断第一个数字是否小于或等于第二个数字，返回“真”或“假”。

+

返回将任意数量的数值块相加的结果。具有数值的块包括基础数字块、“列表的长度”或“文本的长度”块、保存数值的变量等。该块是变体块（mutator），可以展开，以便在求和式中加入更多数字。

-

*

返回将任意数量的数值块相乘的结果。它是变体块（mutator），可以展开，以便在乘积式中加入更多数字。

/

返回第一个数字除以第二个数字的结果。

^

返回第一个数字的第二个数字次幂的结果。

随机整数

返回给定两个值之间（含两端）的随机整数值。参数的先后顺序不影响结果。

随机小数

返回 0 和 1 之间的随机数值。

设随机数种子为

用这个块可以生成可重复的随机数序列。只要先用相同的值调用“设随机数种子为”块，就能得到相同的随机数序列。这在测试涉及随机值的程序时很有用。

最小值

返回一组数字中的最小值。如果块中有未插入内容的插槽，“最小值”也会把 0 计入这组数字。该块既是变体块（mutator），也带下拉菜单。

最大值

返回一组数字中的最大值。如果块中有未插入内容的插槽，“最大值”也会把 0 计入这组数字。该块既是变体块（mutator），也带下拉菜单。

平方根

返回给定数字的平方根。

绝对值

返回给定数字的绝对值。

负数值

返回给定数字的负数值。

对数值

返回给定数字的自然对数，即以 e（2.71828…）为底的对数。

e的乘方

返回 e（2.71828…）的给定数字次幂。

四舍五入

返回给定数字四舍五入到最接近的整数后的结果。如果小数部分 < .5，就向下取整；如果 > .5，就向上取整；如果恰好等于 .5，则整数部分为偶数的数字向下取整，整数部分为奇数的数字向上取整。（这种方法称为向偶数舍入。）

就高取整

返回大于或等于给定数字的最小整数。

就低取整

返回小于或等于给定数字的最大整数。

模数

当 a 和 b 都为正数时，Modulo(a,b) 与 remainder(a,b) 的结果相同。更一般地说，对任意 a 和 b，modulo(a,b) 都满足 (floor(a/b)× b) + modulo(a,b) = a。例如，modulo(11, 5) = 1，modulo(-11, 5) = 4，modulo(11, -5) = -4，modulo(-11, -5) = -1。Modulo(a,b) 的符号始终与 b 相同，而 remainder(a,b) 的符号始终与 a 相同。

余数

Remainder(a,b) 返回 a 除以 b 后取余数的结果。余数等于结果的小数部分乘以 b。

例如，remainder(11,5) = 1，因为

11 / 5 = 2 1⁄5

在这里，1⁄5 就是小数部分。把它乘以 b（这里是 5），得到 1，也就是余数。

其他例子：remainder(-11, 5) = -1，remainder(11, -5) = 1，remainder(-11, -5) = -1。

商数

返回第一个数字除以第二个数字并舍去结果小数部分后的值。

正弦

返回给定角度（单位为度）的正弦值。

余弦

返回给定角度（单位为度）的余弦值。

正切

返回给定角度（单位为度）的正切值。

反正弦

返回给定值的反正弦角度（单位为度）。

反余弦

返回给定值的反余弦角度（单位为度）。

反正切

返回给定值的反正切角度（单位为度）。

坐标的反正切

给定 y 和 x，返回 y/x 的反正切值。

由弧度转角度

返回给定弧度值对应的角度值。结果是一个范围在 [0, 360) 内的角。

由角度转弧度

返回给定角度值对应的弧度值。结果是一个范围在 [-π, +π) 内的角。

求小数值

把数字格式化为保留指定小数位数的十进制数。小数位数必须是非负整数。结果通过对该数字四舍五入（如果小数位数过多）或在右侧补零（如果小数位数不足）得到。

为数字

如果给定对象是数字，则返回“真”，否则返回“假”。

进制转换

接受表示某一进制正整数的文本字符串，返回表示同一数字的另一进制字符串。例如，如果输入的字符串是 10，从十进制转换为二进制会得到字符串 1010；如果输入的字符串同样是 10，从二进制转换为十进制会得到字符串 2；如果输入的字符串同样是 10，从十进制转换为十六进制会得到字符串 A。

按位与

取两个数字，逐位进行比较。只有当两个操作数的对应位都为 1 时，结果中的该位才为 1。

示例：

  十进制 二进制（内部表示）
  6 0 1 1 0
  3 0 0 1 1
结果： 2 0 0 1 0

按位或（包含式）

取两个数字，逐位进行比较。只要两个操作数中有一个的对应位为 1，结果中的该位就为 1。

示例：

  十进制 二进制（内部表示）
  6 0 1 1 0
  3 0 0 1 1
结果： 7 0 1 1 1

按位异或

取两个数字，逐位进行比较。只有当两个操作数中一个的对应位为 1、另一个为 0 时，结果中的该位才为 1。

示例：

  十进制 二进制（内部表示）
  6 0 1 1 0
  3 0 0 1 1
结果： 5 0 1 0 1
