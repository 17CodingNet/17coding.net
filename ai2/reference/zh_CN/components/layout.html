绝对布局（AbsoluteArrangement）

用于将所含组件按绝对位置排列的容器。

属性

BackgroundColor
以 alpha-red-green-blue 整数指定按钮的背景色。 如果参数为 Component’s COLOR，则恢复原有的斜角效果。 如果已设置图像，则在移除该图像之前，颜色更改不可见。
Height
指定 AbsoluteArrangement 的垂直高度，以像素为单位。
HeightPercent
以 Screen’s Height 的百分比形式 指定 AbsoluteArrangement 的垂直高度。
Image
指定按钮图像的路径。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 AbsoluteArrangement 是否应在屏幕上可见。若 AbsoluteArrangement 正在显示，值为 true； 若已隐藏，值为 false。
Width
指定 AbsoluteArrangement 的水平宽度，以像素为单位。
WidthPercent
以 Screen’s Width 的百分比形式 指定 AbsoluteArrangement 的水平宽度。

水平布局（HorizontalArrangement）

使用水平布局组件可以显示一组自左向右排列的组件。

该组件是一种排版元素，您可以将应自左向右显示的组件放入其中。 如果希望组件一个叠一个地显示，请改用 VerticalArrangement。

在 HorizontalArrangement 中，组件沿水平轴排列，并在垂直方向上 居中对齐。

如果 HorizontalArrangement 的 Height 属性设为 Automatic，则布局的 实际高度由该布局中 Height 属性未设为 Fill Parent 的 最高组件决定。如果 HorizontalArrangment 的 Height 属性设为 Automatic，且它只包含 Height 属性均设为 Fill Parent 的组件，则布局的实际高度 按这些组件的自动高度计算。如果 HorizontalArrangement 的 Height 属性设为 Automatic 且布局为空，则 Height 为 100。

如果 HorizontalArrangement 的 Width 属性设为 Automatic，则布局的 实际宽度由各组件宽度之和决定。如果 HorizontalArrangement 的 Width 属性设为 Automatic，则任何 Width 属性设为 Fill Parent 的组件都将如同设为 Automatic 一样表现。

如果 HorizontalArrangement 的 Width 属性设为 Fill Parent，则各组件的宽度 将平均占用其他组件未占用的宽度。

属性

AlignHorizontal
一个数字，用于编码 HorizontalArrangement 的内容在水平方向上的对齐方式。可选值为： 1 = 左对齐，2 = 右对齐，3 = 水平居中。如果 HorizontalArrangement 的 Width 为 Automatic，则对齐设置不起作用。
AlignVertical
一个数字，用于编码 HorizontalArrangement 的内容在垂直方向上的对齐方式。可选值为： 1 = 顶部对齐，2 = 垂直居中，3 = 底部对齐。 如果 HorizontalArrangement 的 Height 为 Automatic，则对齐设置不起作用。
BackgroundColor
以 alpha-red-green-blue 整数指定 HorizontalArrangement 的背景色。 如果已设置图像，则在移除该图像之前，颜色更改不可见。
Height
指定 HorizontalArrangement 的垂直高度，以像素为单位。
HeightPercent
以 Screen’s Height 的百分比形式 指定 HorizontalArrangement 的垂直高度。
Image
指定 HorizontalArrangement 背景图片的路径。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 HorizontalArrangement 是否应在屏幕上可见。若 HorizontalArrangement 正在显示，值为 true； 若已隐藏，值为 false。
Width
指定 HorizontalArrangement 的水平宽度，以像素为单位。
WidthPercent
以 Screen’s Width 的百分比形式 指定 HorizontalArrangement 的水平宽度。

表格布局（TableArrangement）

使用表格布局组件可以按表格形式显示一组组件。

该组件是一种排版元素，您可以将应以表格形式显示的组件 放入其中。

在 TableArrangement 中，组件按行和列组成的网格排列， 每个单元格中可见的组件不超过一个。如果多个组件占据同一个 单元格，则只有最后一个可见。

在每一行内，组件在垂直方向上居中对齐。

列的宽度由该列中最宽的组件决定。计算 列宽时，对于 Width 属性设为 Fill Parent 的组件，使用其自动宽度。但是，每个组件始终会填满其 所占据列的完整宽度。

行的高度由该行中 Height 属性未设为 Fill Parent 的最高组件决定。如果某一行只包含 Height 属性均设为 Fill Parent 的组件，则该行的高度按这些组件的 自动高度计算。

属性

Columns
确定表格中的列数。
Height
指定 TableArrangement 的垂直高度，以像素为单位。
HeightPercent
以 Screen’s Height 的百分比形式 指定 TableArrangement 的垂直高度。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Rows
确定表格中的行数。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 TableArrangement 是否应在屏幕上可见。若 TableArrangement 正在显示，值为 true； 若已隐藏，值为 false。
Width
指定 TableArrangement 的水平宽度，以像素为单位。
WidthPercent
以 Screen’s Width 的百分比形式 指定 TableArrangement 的水平宽度。

垂直布局（VerticalArrangement）

使用 VerticalArrangement 组件可以显示一组自上而下排列、 左对齐的组件。

该组件是一种排版元素，您可以将应一个接一个向下显示的组件 放入其中。第一个子组件存放在顶部，第二个在其下方，依此类推。 如果希望组件彼此并排显示，请改用 HorizontalArrangement。

在 VerticalArrangement 中，组件沿垂直轴排列，左对齐。

如果 VerticalArrangement 的 Width 属性设为 Automatic，则布局的 实际宽度由该布局中 Width 属性未设为 Fill Parent 的 最宽组件决定。如果 VerticalArrangement 的 Width 属性设为 Automatic，且它只包含 Width 属性均设为 Fill Parent 的组件，则布局的实际宽度 按这些组件的自动宽度计算。如果 VerticalArrangement 的 Width 属性设为 Automatic 且布局为空，则宽度为 100。

如果 VerticalArrangement 的 Height 属性设为 Automatic，则布局的 实际高度由各组件高度之和决定。如果 VerticalArrangement 的 Height 属性设为 Automatic，则任何 Height 属性设为 Fill Parent 的组件都将如同设为 Automatic 一样表现。

如果 VerticalArrangement 的 Height 属性设为 Fill Parent 或以像素 指定，则任何 Height 属性设为 Fill Parent 的组件都将平均占用 其他组件未占用的高度。

属性

AlignHorizontal
一个数字，用于编码 VerticalArrangement 的内容在水平方向上的对齐方式。可选值为： 1 = 左对齐，2 = 右对齐，3 = 水平居中。如果 VerticalArrangement 的 Width 为 Automatic，则对齐设置不起作用。
AlignVertical
一个数字，用于编码 VerticalArrangement 的内容在垂直方向上的对齐方式。可选值为： 1 = 顶部对齐，2 = 垂直居中，3 = 底部对齐。 如果 VerticalArrangement 的 Height 为 Automatic，则对齐设置不起作用。
BackgroundColor
以 alpha-red-green-blue 整数指定 VerticalArrangement 的背景色。 如果已设置图像，则在移除该图像之前，颜色更改不可见。
Height
指定 VerticalArrangement 的垂直高度，以像素为单位。
HeightPercent
以 Screen’s Height 的百分比形式 指定 VerticalArrangement 的垂直高度。
Image
指定 VerticalArrangement 背景图片的路径。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 VerticalArrangement 是否应在屏幕上可见。若 VerticalArrangement 正在显示，值为 true； 若已隐藏，值为 false。
Width
指定 VerticalArrangement 的水平宽度，以像素为单位。
WidthPercent
以 Screen’s Width 的百分比形式 指定 VerticalArrangement 的水平宽度。
