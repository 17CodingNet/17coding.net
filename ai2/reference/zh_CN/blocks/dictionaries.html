简介

字典在别的语言里也叫映射（map）、关联数组（associative array）或列表，它是一种把某个值（通常称为键）与另一个值关联起来的数据结构。展示字典的常见方式是使用 JavaScript 对象表示法（JSON），例如：

{
  "id":  1,
  "name":  "Tim the Beaver",
  "school": {
    "name": "Massachusetts Institute of Technology"
  },
  "enrolled": true,
  "classes": ["6.001", "18.01", "8.01"]
}

上面的例子说明，在 JSON 中键（: 前面的带引号文本）可以映射到不同类型的值。允许的类型有数字、文本、其他字典、布尔值和列表。在块语言中，您可以按下面的方式构建这个字典：

图 1：上面所示 JSON 代码片段的块表示形式。

空字典

create empty dictionary 块创建一个不含任何键值对的字典。可以使用 set value for key 块向这个空字典添加数据项。create empty dictionary 块还可以通过蓝色变体按钮添加 pair 项，从而转变成 make a dictionary 块。

建立字典

make a dictionary 用于创建带有若干事先确定好的 pair 的字典。还可以用 set value for key 添加更多数据项。

键值对

pair 块是用于构建字典的专用块。

查询字典

get value for key 块会检查字典中是否存在与给定键对应的值。如果存在，就返回该值；否则返回 not found 参数的值。这一行为与 lookup in pairs 块类似。

设字典键对应值

set value for key 块把 dictionary 中给定 key 对应的值设为 value。如果该 key 还没有映射，就新建一个映射；否则，原有的值会被新值替换。

删除字典键值对

delete entry for key 块会删除字典中给定键对应的键值映射。如果字典中不存在该键对应的数据项，则字典保持不变。

字典中键路径对应值

get value at key path 块是 get value for key 块的进阶版本。它不是获取某个特定键的值，而是接收一个由有效键和数字组成的列表，用来表示在数据结构中穿行的路径。使用本块并传入长度为 1、只包含该键的键路径，就相当于 get value for key 块。例如，下面两个块都会返回 "Tim the Beaver"：

它从初始字典开始，按照提供的 path 在数据结构中穿行，以取出嵌套在复杂结构深处的值，最适合用来处理来自网络服务的 JSON 数据。它从初始输入开始，取出 key path 中的第一个元素，检查该处是否存在相应的键（如果输入是字典）或索引（如果输入是列表）。如果存在，就选中该项作为输入，继续检查 key path 中的下一个元素；如此继续，直到走完整条路径——此时返回该位置的内容——或者返回 "not found" 参数。

示例

{
  "id":  1,
  "name":  "Tim the Beaver",
  "school": {
    "name": "Massachusetts Institute of Technology"
  },
  "enrolled": true,
  "classes": ["6.001", "18.01", "8.01"]
}

例如，对于上面的 JSON 字典，下面这样使用 get value at key path 会得到结果 "Massachusetts Institute of Technology"。

设字典中键路径对应值

set value for key path 块会更新数据结构中特定 key path 处的值。它与 get value for key path 相对应，后者用于获取特定 key path 处的值。路径必须有效，只有最后一个键例外：如果该键还没有映射，就会新建一个指向新值的映射；否则，原有的值会被新值替换。

全部键

get keys 返回字典中所有键组成的列表。

全部值

get values 返回包含字典中所有值的列表。修改列表中某个值的内容，字典中的该值也会随之改变。

检查字典中是否存在指定键

is key in dictionary? 检查该键是否存在于字典中：如果存在就返回 true，否则返回 false。

字典的长度

size of dictionary 块返回字典中键值对的个数。

键值对转字典

list of pairs to dictionary 块把形如 ((key1 value1) (key2 value2) ...) 的关联列表转换为把键映射到其值的字典。 由于字典的查找性能优于关联列表，如果您要在一份数据结构上执行大量操作，建议先用这个块把关联列表转换为字典。

字典转键值对

dictionary to list of pairs 把字典转换为关联列表。 该块执行的是 list of pairs to dictionary 块的反向转换。

复制字典

copy dictionary 对给定的字典做深复制（deep copy），也就是说所有值都会被递归复制，因此修改副本中的某个值不会影响原字典。

字典组合

merge into dictionary from dictionary 块把一个字典中的键值对复制到另一个字典中，并覆盖目标字典中同名的键。

字典或列表中键路径对应值列表

list by walking key path 块的用法与 get value at key path 类似，但它生成的是一个值的列表，而不是返回单个值。它从给定的字典出发，沿给定路径在对象树中逐层向下穿行。不过与 get value at key path 不同的是，它的路径可以由三类主要元素组成：字典的键、列表的索引，以及 walk all at level 块。如果给出的是键或索引，就在树的该位置走对应的那一条路径；如果指定的是 walk all at level，则该位置上的每个值都会被依次访问（广度优先），随后遍历从路径中的下一个元素继续。凡与整条路径匹配的元素，都会加入输出的列表。

示例

请看下面的 JSON 和块：

{
  "people": [{
    "first_name": "Tim",
    "last_name": "Beaver"
  },{
    "first_name": "John",
    "last_name": "Smith"
  },{
    "first_name": "Jane",
    "last_name": "Doe"
  }]
}

如果 global data 保存了由该 JSON 表示的字典，那么 list by walking key path 块会生成列表 ["Tim", "Beaver"]。首先选取 "people" 这个标签的值，也就是人员列表；接着选取列表中的第一个元素；最后，walk all at level 块选取该位置对象中的各个值，也就是 "Tim" 和 "Beaver"。

您也可以在包含列表的层级上使用 walk all at level。例如，下面的块会选出结构中所有人的名字，即 ["Tim", "John", "Jane"]。

该块也可以配合 Web.XMLTextDecodeAsDictionary 块解析得到的 XML 一起使用。请看下面的 XML 文档：

<schedule>
  <day>
    <room name="Hewlitt" />
    <room name="Bleil" />
  </day>
  <day>
    <room name="Kiva" />
    <room name="Star" />
  </day>
</schedule>

您可以用下面的块得到第一天各房间名称的列表，即 ["Hewlitt", "Bleil"]。

当前全部节点

walk all at level 块是一个专用块，可以用在 list by walking key path 的键路径中。遍历过程中遇到它时，该层级上的每一项都会被探查。对于字典，这意味着访问每一个值；对于列表，则访问列表中的每一项。它可用于汇总字典中一组数据项的信息，例如由 JSON 对象表示的数据库中每个人的名字。示例请参见 list by walking key path 块。

是否为字典

is a dictionary? 块检查传给它的 thing 是不是字典。返回 true 表示 thing 是字典，返回 false 则表示不是。
