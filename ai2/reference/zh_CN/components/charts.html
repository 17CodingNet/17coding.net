图表（Chart）

Chart 组件绘制来自与其关联的数据组件的数据。它有五种不同的 图表类型，包括线条图、面积图、散点图、柱状图和饼状图，可以通过 Type 属性更改。 Chart 组件自身还有许多其他改变图表外观的属性， 例如 {Description、GridEnabled、

属性

AxesTextColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定图表的坐标轴文字颜色。
BackgroundColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定图表的背景色。
Description
指定图表内描述标签所显示的文本。 指定空字符串（“”）将不显示任何标签。
GridEnabled
改变图表网格的可见性，前提是 图表类型被设置为带坐标轴的图表（适用于面积图、柱状图、线条图、 散点图类型）。
Height
以像素为单位指定 Chart 的垂直高度。
HeightPercent
以 Screen 的 Height 的百分比形式指定 Chart 的垂直高度。
Labels
把图表的 X 轴标签改为指定的列表， 前提是图表的类型被设置为带坐标轴的图表。

列表的第一个条目对应数据的最小 x 值， 第二个对应最小 x 值 + 1，依此类推。

如果没有为某个 x 值指定标签，则使用默认值 （该位置坐标轴刻度的 x 值）。

LabelsFromString
指定要对图表 X 轴设置的标签，前提是当前 视图是带 X 轴的图表。这些标签以单个用半角逗号分隔的 值的字符串给出（即每个值用逗号分隔）。标签如何应用到图表上的更多细节， 请见 Labels。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
LegendEnabled
改变图表图例的可见性。
PieRadius
设置图表的饼图半径。如果当前类型 不是饼状图，该值不起作用。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Type
指定图表的类型，它决定如何把数据可视化。
ValueFormat
指定 X 轴标签和点值的格式。
Visible
指定 Chart 是否应在屏幕上可见。若 Chart 正在显示，值为 true， 若已隐藏，值为 false。
Width
以像素为单位指定 Chart 的水平宽度。
WidthPercent
以 Screen 的 Width 的百分比形式指定 Chart 的水平宽度。
XFromZero
决定 X 轴原点设为 0，还是设为所有数据系列中的 最小 X 值。
YFromZero
决定 Y 轴原点设为 0，还是设为所有数据系列中的 最小 y 值。

事件

EntryClick(series,x,y)
表示用户点击了 Chart 中的某个数据条目。会报告具体的系列，以及 它的 x 和 y 值。

方法

ExtendDomainToInclude(x)
扩展图表的定义域以包含给定的 x 值。如果 x 已经处于 定义域范围内，此方法不起作用。
ExtendRangeToInclude(y)
扩展图表的值域以包含给定的 y 值。如果 y 已经处于 值域范围内，此方法不起作用。
ResetAxes()
把图表的坐标轴重置为其初始界限。
SetDomain(minimum,maximum)
设置 X 轴定义域的最小值和最大值。
SetRange(minimum,maximum)
设置 Y 轴值域的最小值和最大值。

数据（ChartData2D）

ChartData2D 组件代表 Chart 组件中的单个二维数据系列， 例如线条图中的单条线，或者柱状图中的单根柱子。数据组件负责处理图表的 全部数据。数据组件的条目对应一个 x 值和一个 y 值。 把该组件直接拖放到 Chart 上，即可将其关联到 Chart 组件。

属性

Color
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定数据系列的颜色。
Colors
以 alpha-red-green-blue（透明度-红-绿-蓝）整数列表指定数据系列的颜色。

如果数据比颜色多，颜色会按顺序轮换使用。例如，如果有红、蓝两种 颜色，颜色会按以下顺序应用：红、蓝、红、蓝、……

DataFileXColumn
从 DataFile 组件 Source 导入数据时使用的值。该 值表示从 DataFile 中为数据系列的 x 条目取用哪一列。例如，如果某一列 的第一个值是 “Time”，并且指定了列值 “Time”，则该列将被用于 x 值。如果这里未指定值，则会改为为 x 值生成 默认值。
DataFileYColumn
从 DataFile 组件 Source 导入数据时使用的值。该 值表示从 DataFile 中为数据系列的 y 条目取用哪一列。例如，如果某一列 的第一个值是 “Temperature”，并且指定了列值 “Temperature”，则该列将被用于 y 值。如果这里未指定值，则会改为为 y 值生成 默认值。
DataLabelColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定数据点标签的颜色。
DataSourceKey
设置要从所关联的数据源导入值的数据源键标识符。

一个例子是 TinyDB 组件的标签，它用于标识该值。

该属性是仅设计视图属性，应当在设置图表数据组件的 Source 组件之后再修改。

对于每种兼容的数据源，适用的完整取值列表如下：

  • 对于 TinyDB 和 CloudDB，这是标签值。
  • 对于 AccelerometerSensor，该值应当是下列之一：X、Y 或 Z
  • 对于 GyroscopeSensor，该值应当是下列之一：X、Y 或 Z
  • 对于 LocationSensor，该值应当是下列之一： latitude、longitude、altitude 或 speed
  • 对于 OrientationSensor，该值应当是下列之一： pitch、azimuth 或 roll
  • 对于 Pedometer，该值应当是下列之一： WalkSteps、SimpleSteps 或 Distance
  • 对于 ProximitySensor，该值应当是 distance。
  • 对于 BluetoothClient，该值表示要从值中移除的前缀。 例如，如果值以 “t:12” 的格式传入，可以把前缀指定为 “t:”， 随后该前缀会从数据中移除。如果返回的是纯 数值，则不能指定任何值。
ElementsFromPairs
用逗号分隔的、用于数据系列的元素列表。值的格式 如下：x1,y1,x2,y2,x3,y3。值按对取用，由 x 和 y 值 构成一个条目。
Label
指定数据系列标签的文本。
LineType
改变数据系列的线型，前提是该 数据组件关联的图表类型被设置为 基于线条的图表（适用于面积图和线条图类型）。 有效类型包括线性、曲线或阶梯。
PointShape
改变数据系列的点形状，前提是该 数据组件关联的图表类型被设置为 散点图。有效类型包括圆形、方形、三角形、十字、x。
Source
设置数据组件要使用的数据源。有效选项 包括 AccelerometerSensor、BluetoothClient、CloudDB、DataFile、 GyroscopeSensor、LocationSesnro、OrientationSensor、Pedometer、 ProximitySensor TinyDB 和 Web 组件。数据源取值还需要 有效的 DataSourceValue、WebColumn 或 DataFileColumn 属性， 具体取决于所关联数据源的类型（更改数据源后， 所需属性会出现在属性菜单中）。

如果由 DataSourceKey 标识的数据在所关联的数据源组件中 被更新，那么图表数据组件中的数据也会随之更新。

SpreadsheetUseHeaders
如果勾选，电子表格的第一行将用于解释 x 列和 y 列的 取值。否则，x 列和 y 列应当是列引用，例如 A 或 B。
SpreadsheetXColumn
设置从所关联的 Spreadsheet 组件中为 x 值解析哪一列。如果 未指定列，则会改为为 x 值生成默认值。
SpreadsheetYColumn
设置从所关联的 Spreadsheet 组件中为 y 值解析哪一列。如果 未指定列，则会改为为 y 值生成默认值。
WebXColumn
从 Web 组件数据源导入数据时使用的值。该 值表示从 Web 中为数据系列的 x 条目取用哪一列。例如，如果从 Web 获取的内容是 JSON 格式，并且存在一个带有 “Time” 标签的数组， 则可以指定 “Time” 列值来使用该数组。
WebYColumn
从 Web 组件数据源导入数据时使用的值。该 值表示从 Web 中为数据系列的 y 条目取用哪一列。例如，如果从 Web 获取的内容是 JSON 格式，并且存在一个带有 “Temperature” 标签的数组， 则可以指定 “Temperature” 列值来使用该数组。

事件

EntryClick(x,y)
表示用户点击了图表中的某个数据点。会报告被点击条目的 x 和 y 值。

方法

AddEntry(x,y)
添加一个具有指定 x 和 y 值的条目。值可以指定为文本， 也可以指定为数字。对于线条图、散点图、面积图和柱状图，两个值都应当表示数字。 对于柱状图，x 值会四舍五入到最接近的整数。 对于饼状图，x 值是一个文本值。
ChangeDataSource(source,keyValue)
把组件的数据源改为指定的组件 Source，并使用 指定的键值。适用的组件请见 Source 属性。 keyValue 的解释请见 DataSourceKey 属性。 对于 DataFile 和 Web 组件，keyValue 应当是一个 CSV 格式的字符串，其中第一个值对应 x 列，第二个 值对应 y 值。
Clear()
从数据系列中移除所有条目。
DoesEntryExist(x,y)
返回一个布尔值，表示是否存在具有指定 x 和 y 值的条目。如果该值存在则返回布尔值 true， 否则返回 false。关于有效条目值的说明请见 AddEntry。
GetAllEntries()
返回数据系列的所有条目。 返回的是一个列表，其中列表的每个元素 都是一个按顺序包含该条目各值的列表。
GetEntriesWithXValue(x)
返回数据系列中所有匹配指定 x 值的条目。 关于返回列表格式的说明，请见 GetAllEntries
GetEntriesWithYValue(y)
返回数据系列中所有匹配指定 y 值的条目。 关于返回列表格式的说明，请见 GetAllEntries
HighlightDataPoints(dataPoints,color)
用所选的颜色在图表上高亮显示所有给定的数据点。
ImportFromCloudDB(cloudDB,tag)
从指定的 CloudDB 组件导入数据，取用 由指定标签值标识的值。

预期的 CloudDB 值是一个列表，其格式与 ImportFromList 中描述的相同。

不会覆盖任何数据。

ImportFromDataFile(dataFile,xValueColumn,yValueColumn)
从指定的 DataFile 组件导入数据，取用指定的 x 列 作为 x 值，指定的 y 列作为 y 值。DataFile 的源文件 应当是 CSV 或 JSON 文件。

任何列参数若传入空文本，将导致使用 默认值，即条目的索引。对于第一个条目，默认 值会是 1，第二个是 2，依此类推。

ImportFromList(list)
从指定的列表参数把数据导入到数据系列中。 该列表应当包含同时是列表的元素。每个 列表元素应当有 2 个值，第一个是 x 值，第二个是 y 值。 无效的列表条目会被直接跳过。已有数据不会被清除。
ImportFromSpreadsheet(spreadsheet,xColumn,yColumn,useHeaders)
从指定的 Spreadsheet 组件导入数据，取用指定的 x 列 作为 x 值，指定的 y 列作为 y 值。在调用此函数之前， 必须先调用 Spreadsheet 组件的 ReadSheet 方法以加载数据。无需 使用 Spreadsheet 组件中的 GotSheet 事件。

空列会用默认值填充（条目 1、2、3、…… 对应 1、2、3、……）。

ImportFromTinyDB(tinyDB,tag)
从指定的 TinyDB 组件导入数据，取用 由指定标签值标识的值。

预期的 TinyDB 值是一个列表，其格式与 ImportFromList 中描述的相同。

不会覆盖任何数据。

ImportFromWeb(web,xValueColumn,yValueColumn)
从指定的 Web 组件导入数据，取用指定的 x 列 作为 x 值，指定的 y 列作为 y 值。在调用此函数之前， 必须先调用 Web 组件的 Get 方法以加载数据。无需 使用 Web 组件中的 gotValue 事件。

此函数要正常工作，Web 组件返回的响应应当是 JSON 或 CSV 格式的文件。

空列会用默认值填充（条目 1、2、3、…… 对应 1、2、3、……）。

RemoveDataSource()
从图表数据组件中移除当前关联的数据源。 这样做将不再发送来自该数据源的更新，不过， 当前数据不会被移除。
RemoveEntry(x,y)
移除具有指定 x 和 y 值的条目，前提是它存在。 关于有效条目值的说明请见 AddEntry。

拟合线（Trendline）

Trendline 组件可用于把 ChartData2D 组件所代表的数据系列的趋势可视化。 它必须被添加到 Chart 组件中。要关联一个 ChartData2D 实例，可以在应用的设计视图中设置 ChartData 属性，或者使用设置器 块。如果其关联的 ChartData2D 发生变化，趋势线会自动更新。

趋势线有四种可用模型：线性、二次、对数和 指数。根据您使用的是哪种模型，趋势线组件的某些属性 会提供相关的值。

  • 线性：y = m*x + b，其中 m 是 LinearCoefficient，b 是 YIntercept
  • 二次：y = a*x2 + b*x + c，其中 a 是 QuadraticCoefficient，b 是 LinearCoefficient，c 是 YIntercept
  • 对数：y = a + b*ln(x)，其中 a 是 LogarithmConstant，b 是 LogarithmCoefficient
  • 指数：y = a*bx，其中 a 是 ExponentialCoefficient，b 是 ExponentialBase

对于所有模型，r2 相关性都会通过 RSquared 属性 块报告。

属性

ChartData
要计算最佳拟合线的数据系列。
Color
最佳拟合线的颜色。
CorrelationCoefficient
趋势线与数据的相关系数。
ExponentialBase
方程 y = a*b^x 中指数项的底数。
ExponentialCoefficient
方程 y = a*b^x 中指数项的系数。
Extend
是否把最佳拟合线延伸到数据之外。
LinearCoefficient
趋势线中一次项的系数。
LogarithmCoefficient
方程 y = a + b*ln(x) 中对数项的系数。
LogarithmConstant
对数方程 y = a + b*ln(x) 中的常数项。
Model
用于最佳拟合线的模型。
Predictions
趋势线的预测值。
QuadraticCoefficient
趋势线中二次项的系数（若有）。
RSquared
趋势线的 r 平方决定系数。
Results
获取最佳拟合线最近一次计算所得各值的一份副本。
StrokeStyle
最佳拟合线的样式。
StrokeWidth
最佳拟合线的宽度。
Visible
最佳拟合线是否可见。
XIntercepts
趋势线与 X 轴的交点（线穿过 X 轴处），若有。可能的 值有 NaN（无交点）、单个值（一个交点），或值的列表。
YIntercept
趋势线的 Y 轴截距（常数项）。

事件

Updated(results)
表示最佳拟合线已更新的事件。

方法

DisconnectFromChartData()
断开趋势线与之前关联的 ChartData2D 之间的关联。
GetResultValue(value)
获取最佳拟合线最近一次计算所得各值中的某个字段。可用的 值随所使用的模型而不同。例如，线性模型会有 slope 和 Yintercept 字段，而二次模型会有 x^2、slope 和 intercept 字段。
