如果 & 否则，如果

测试给定的条件。如果条件为真，则执行指定代码块序列中的动作；否则忽略这些代码块。

遍历指定范围数据

对“范围从”与“到”之间的每一个数值，都运行“执行”区域中的代码块，每次让 number 递增“且增量为”的值。使用给定的变量名 number 引用当前值；如有需要，您也可以把名称 number 改成其他名字。

逐项遍历列表

针对列表中的每一项运行“执行”区域中的代码块。使用给定的变量名 item 引用当前列表项；如有需要，您也可以把名称 item 改成其他名字。

针对字典中每对键值

针对字典中的每一对键值，运行“执行”区域中的代码块。使用给定的变量 key 和 value 引用当前字典项的键和值；如有需要，您也可以把名称 key 和 value 改成其他名字。

只要满足条件

检测“条件”处的条件。如果为真，就执行“执行”区域中给出的动作，然后再次检测。当条件为假时，该块结束，“执行”区域中给出的动作不再执行。

如果…则…否则

测试给定的条件。如果语句为真，则执行“则”返回序列中的代码块并返回“则”的返回值；否则执行“否则”返回序列中的代码块并返回“否则”的返回值。该块类似于某些语言中的三元运算符（?:）。

执行并返回

有时在过程或其他代码块中，您可能需要先做某件事再返回某个结果，但由于种种原因，您可以选择使用该块，而不必新建一个过程。

执行但不返回结果

提供一个“虚拟插槽”，用于把左侧带插头的块接到没有插槽的位置，例如“如果”块或过程“执行”部分中的代码块序列。您接入的块会运行，但它返回的结果会被忽略。当您定义了一个有返回值的过程，却想在不需要结果的位置调用它时，这个块会很有用。

打开屏幕

打开指定名称的屏幕。

screenName 必须是使用设计器创建的屏幕之一。 screenName 应当从已连接的屏幕名称下拉块中选择。

如果确实打开了另一个屏幕，在返回主屏幕时应当把它关闭，以释放系统内存。离开屏幕时不将其关闭，最终会导致内存问题。

应用开发者绝不应关闭 Screen1，也不应使用该块返回 Screen1。请改用 close screen（关闭当前屏幕）块。

打开屏幕并传值

打开另一个屏幕，并向它传递一个值。

应用初始值

返回本屏幕由其他应用启动时传入的纯文本。如果没有传入任何值，则返回空文本。对于多屏应用，请使用 get start value（屏幕初始值），而不要使用 get plain start text（应用初始值）。

屏幕初始值

返回赋予当前屏幕的初始值。

该值由 open another screen with start value（打开屏幕并传值）或 close screen with value（关闭屏幕并返回值）给出。

关闭当前屏幕

关闭当前屏幕。

关闭屏幕并返回应用值

关闭当前屏幕，并向打开它的应用传递文本。该命令用于向非 App Inventor 的活动（activity）返回文本，而不是向 App Inventor 屏幕返回文本。对于 App Inventor 屏幕（如多屏应用中），请使用 close screen with value（关闭屏幕并返回值），而不要使用 close screen with plain text（关闭屏幕并返回应用值）。

关闭屏幕并返回值

关闭当前屏幕，并向打开它的屏幕返回一个值。

退出程序

退出应用程序。

终止循环

使用遍历指定范围数据、逐项遍历列表或只要满足条件块进行循环时，有时需要提前退出循环。break（终止循环）可以让您跳出循环。执行时，它会退出循环，并从循环之后的代码块继续运行应用。
