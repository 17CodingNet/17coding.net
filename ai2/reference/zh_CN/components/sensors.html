加速度传感器（AccelerometerSensor）

用于检测晃动并以国际单位制（m/s2）近似测量三个维度上加速度的非可视组件。三个分量分别为：

  • xAccel：当手机静止于平面上时为 0；手机向右倾斜（即左侧抬起）时为正；手机向左倾斜（即右侧抬起）时为负。
  • yAccel：当手机静止于平面上时为 0；底部抬起时为正，顶部抬起时为负。
  • zAccel：等于 -9.8（地球重力加速度，单位为米每平方秒）；当设备静止并与地面平行且屏幕朝上时为 -9.8，垂直于地面时为 0，屏幕朝下时为 +9.8。该值也会因顺着或逆着重力方向加速设备而改变。

属性

Available
返回设备上是否有 AccelerometerSensor 硬件可用。
Enabled
指定传感器是否应生成事件。若为 true， 传感器将生成事件；否则即使设备被加速或晃动，也不会生成任何事件。
LegacyMode
在引入本属性的版本之前，AccelerometerSensor 组件直接原样传递从 Android 系统接收到的传感器值。然而这些值并未针对默认为横屏模式的平板电脑进行补偿，需要 App Inventor蔻丁工坊 程序员自行补偿。但如果自行补偿，在手机等竖屏模式的设备上又会得到错误的结果。现在我们会检测横屏模式的平板电脑并自动执行补偿。但如果您的项目已经在自行补偿，现在就会得到错误的结果。虽然我们推荐的解决方案是更新您的项目，您也可以直接将该属性设为“true”，这样我们的补偿代码就会被停用。注意：我们建议您更新项目，因为在未来的版本中我们可能会移除该属性。
MinimumInterval
指定连续的 Shaking 事件之间所需的最小间隔， 以毫秒为单位。 一旦手机开始被晃动，在间隔时间过去之前，后续所有 Shaking 事件都会被忽略。
Sensitivity
指定加速度计的灵敏度。有效取值为：1（弱）、2（中等） 和 3（强）。
XAccel
返回 X 维度上的加速度，单位为国际单位制（m/s²）。 传感器必须启用才能返回有意义的值。
YAccel
返回 Y 维度上的加速度，单位为国际单位制（m/s²）。 传感器必须启用才能返回有意义的值。
ZAccel
返回 Z 维度上的加速度，单位为国际单位制（m/s²）。 传感器必须启用才能返回有意义的值。

事件

AccelerationChanged(xAccel,yAccel,zAccel)
表示 X、Y 和/或 Z 维度上的加速度发生了变化。
Shaking()
表示设备开始被晃动，或持续处于晃动状态。

方法

无

计时器（Clock）

使用手机的内部时钟提供时间点的非可视组件。 它可按设定的固定间隔触发计时器，并执行时间计算、处理和转换。

对日期和时间的操作，例如来自 DatePicker 和 TimePicker 的操作，都通过 Clock 中的方法完成。日期和 时间用 InstantInTime 和 Duration 表示。

  • Instant（时间点）：由年、月、日、时、分、秒组成。可以使用 MakeInstant、MakeInstantFromMillis 和 MakeInstantFromParts 方法创建一个时间点。
  • Duration（时长）：两个时间点之间经过的时间，以毫秒为单位。可通过 Duration 方法获取时长。

时间点假定位于设备的本地时区。在时间点与毫秒值之间相互转换时，给定时间点的毫秒值 是在 UTC（格林尼治标准时间）下从 1970 年 1 月 1 日开始计算的。

还提供了将时间点转换为文本的方法。可接受的模式有：空字符串、 MM/dd/YYYY HH:mm:ss a 或 MMM d, yyyy HH:mm。空字符串将提供默认 格式：对于 FormatDateTime 为 "MMM d, yyyy HH:mm:ss a"， 对于 FormatDate 为 "MMM d, yyyy"。要查看所有可能的格式， 请参见这里。

关于组合日期和时间的说明：若要将一个时间点的日期与另一个时间点的时间组合起来， 例如来自 DatePicker 和 TimePicker 的日期与时间，请将这些部分提取为文本， 再用这些文本创建一个新的时间点。例如：

指定是否应运行 Timer 事件。

指定相邻两次 Timer 事件之间的间隔。

注意：随时间推移可能会出现漂移，而且如果应用或手机上的其他进程正忙，系统可能不会遵守 此处指定的计时。

位置传感器（LocationSensor）

提供位置信息的非可视组件，包括 Latitude、 Longitude、Altitude（如果设备支持）、速度（如果设备支持） 和地址。该组件还可以执行“地理编码”，将给定的地址（不一定是当前位置）转换为纬度（使用 LatitudeFromAddress 方法）和经度（使用 LongitudeFromAddress 方法）。

要使其正常工作，组件的 Enabled 属性必须设为 true，并且设备必须通过无线网络或 GPS 卫星（如果在户外）启用位置感应。

应用启动时位置信息可能不会立即可用。您需要等待一小段时间，直到找到并使用某个位置 提供程序，或者等待 LocationChanged 事件。

模拟器并不会在所有设备上模拟传感器。代码应在真实设备上进行测试。

属性

Accuracy
根据卫星、基站及其他用于估算位置的数据的质量，LocationSensor 能够以不同的置信度 定位设备。Accuracy 值是以米为单位的半径，围绕传感器检测到的位置。设备 有 68% 的概率位于该半径之内。位置检测越精确，精度数值就越小，应用也就 越能确信设备的实际位置。

如果精度未知，返回值为 0.0

Altitude
设备的海拔高度，以米为单位（如果可用）。

海拔高度是从 World Geodetic System 84 参考椭球体 起算的，而不是从海平面起算。

请注意，设备很难精确感知海拔高度。手机/平板电脑报告的海拔高度 很容易出现 30 米或更大的偏差。

AvailableProviders
可用服务提供程序的列表，例如 gps 或 network。该信息以列表和 文本两种形式提供。
CurrentAddress
来自 Google 地图数据库的设备实际街道地址。

提供程序可能并不总能提供地址，而且报告的地址也可能并不总是 设备所在的那栋建筑。

如果 Google 没有某个特定位置的地址信息，则返回 No address available。

DistanceInterval
确定传感器在发送位置更新时尝试使用的最小距离间隔，以米为单位。例如，若将其设为 50， 则传感器只有在移动超过 50 米后才会引发 LocationChanged 事件。但传感器并不保证恰好按该距离间隔收到更新。 例如，可能需要超过 5 米才会引发一次事件。

使用该属性时，对照 Accuracy 进行检查也很有用。当您的 设备移动时，检测到的位置的精度会不断变化。

Enabled
若为 true，LocationSensor 将尝试从 GPS、WiFi 定位 或设备上可用的其他方式读取位置信息。该设置并不控制 位置信息是否实际可用。必须在设备设置中启用或 禁用设备定位。
HasAccuracy
若为 true，设备可以报告其精度等级。
HasAltitude
若为 true，设备可以报告其海拔高度。
HasLongitudeLatitude
若为 true，设备可以报告经度和纬度。二者 总是同时具备或同时不具备。
Latitude
最近一次可用的纬度值，以度为单位，保留 5 位小数。 如果没有可用值，将返回 0。 纬度是介于 90（北）和 -90（南）之间的值，其中 0 表示赤道。
Longitude
最近一次可用的经度值，以度为单位，保留 5 位小数。 如果没有可用值，将返回 0。 经度是介于 180（东）和 -180（西）之间的值，其中 0 表示本初子午线。
ProviderLocked
设备不会更换服务提供程序。

当当前提供程序无法提供足够的位置信息时，设备可能会切换服务提供程序。 ProviderLocked 是布尔值：true/false。 设为 true 可阻止提供程序更换。设为 false 则允许在必要时自动切换。

ProviderName
当前的服务提供程序。该提供程序很可能是 GPS 或 network。
TimeInterval
确定传感器在发送位置更新时尝试使用的最小时间间隔，以毫秒为单位。但只有当手机的 位置确实发生变化时才会收到位置更新，且不保证会使用指定的时间间隔。例如，若将 30000 用作时间间隔，则位置更新绝不会快于 30000ms 引发，但可能在之后的任意时刻引发。

对于大多数设备来说，小于 30000ms（30 秒）的值并不实用。较小的值 可能会耗尽电池电量并使 GPS 过度工作。

事件

GotAddress(address)
响应 ReverseGeocode 请求，报告地址。
GotLocationFromAddress(address,latitude,longitude)
响应 Geocode 请求，报告纬度和经度。
LocationChanged(latitude,longitude,altitude,speed)
表示检测到了新的位置。速度以米/秒为单位报告， 其他值与其对应属性一致。
StatusChanged(provider,status)
表示位置提供程序服务的状态已发生变化，例如某个 提供程序丢失或开始使用新的提供程序。

方法

Geocode(address)
通过 GotLocationFromAddress 事件将地址转换为纬度和经度。
LatitudeFromAddress(locationName)
从给定的 locationName 推导出纬度。
LongitudeFromAddress(locationName)
从给定的 locationName 推导出经度。
ReverseGeocode(latitude,longitude)
确定与给定的纬度和经度关联的地址，并通过 GotAddress 事件报告。

方向传感器（OrientationSensor）

使用方向传感器组件来确定手机的空间方位。

方向传感器是一种非可视组件，以角度为单位报告以下三个值：

  • Roll（翻转角）：当设备水平放置时，其值为 0 度；随着设备向左倾斜抬起，增大到 90 度； 而当设备向右倾斜抬起时，减小到 −90 度。
  • Pitch（倾斜角）：当设备水平放置时，其值为 0 度；随着设备倾斜使其顶部朝下， 增大到 90 度，然后随着继续翻转减小到 0 度。 类似地，当设备倾斜使其底部朝下时，倾斜角减小到 −90 度， 然后随着完全翻转过来增大到 0 度。
  • Azimuth（方位角）：当设备顶部指向正北时为 0 度，指向正东时为 90 度， 指向正南时为 180 度，指向正西时为 270 度， 依此类推。

这些测量均假定设备本身不处于移动状态。

属性

Angle
返回一个角度，表示设备倾斜的方向。也就是说，它表示一个 在设备表面滚动的球所感受到的力的方向。
Available
表示设备上是否存在方向传感器。
Azimuth
返回设备的方位角。 要返回有意义的值，必须启用传感器。
Enabled
指定方向传感器是否已启用。
Magnitude
返回一个 0 到 1 之间的数字，表示设备的倾斜程度。 它给出一个在设备表面滚动的球所感受到的力的大小。 若要获取倾斜角度，请使用 Angle。
Pitch
返回设备的倾斜角。 要返回有意义的值，必须启用传感器。
Roll
返回设备的翻转角。 要返回有意义的值，必须启用传感器。

事件

OrientationChanged(azimuth,pitch,roll)
当方位发生变化时，会运行 OrientationChanged 事件处理程序。

方法

无

计步器（Pedometer）

该组件使用加速度计统计步数。

属性

Distance
返回以米为单位的大致行走距离。
ElapsedTime
返回自计步器启动以来经过的时间，以毫秒为单位。
SimpleSteps
返回自计步器启动以来所走的简单步数。
StopDetectionTimeout
返回进入“停止”状态之前所需的静止（未检测到步数）持续时间。
StrideLength
返回当前估算的步幅长度，以米为单位（如果已校准）；否则返回 默认值（0.73 m）。
WalkSteps
返回自计步器启动以来所走的行走步数。

事件

SimpleStep(simpleSteps,distance)
当检测到一个原始步时运行该事件。
WalkStep(walkSteps,distance)
当检测到一个行走步时运行该事件。行走步是指看起来参与向前运动的一步。

方法

Reset()
重置步数计数器、距离测量值和运行时间。
Save()
将计步器状态保存到手机。这样，在使用计步器的应用多次启动之间可以累计步数和距离。不同的应用会有各自保存的状态。
Start()
启动计步器。
Stop()
停止计步器。

接近传感器（ProximitySensor）

一种传感器组件，可测量物体相对于设备显示屏幕的接近程度（以 cm 为单位）。该传感器通常 用于判断手机是否正被贴在人的耳朵上，也就是说，它可以让您确定物体距离设备有多远。许多 设备返回以 cm 为单位的绝对距离，但有些设备只返回“近”和“远”两个值。在这种 情况下，传感器通常会在“远”状态报告其最大量程值，在“近”状态报告一个较小的值。 它报告以下值：

  • Distance：物体到设备的距离

属性

Available
报告设备是否有接近传感器。
Distance
返回物体到设备的距离。 传感器必须启用才能返回有意义的值。
Enabled
若为 true，传感器将生成事件；否则不会生成 任何事件。
KeepRunningWhenOnPause
返回 keepRunningWhenOnPause 的值。
MaximumRange
确定传感器的最大量程。有些接近传感器返回表示“近”或“远”的二值。 在这种情况下，传感器通常会在“远”状态报告 其最大量程值，在“近”状态报告一个较小的值。 通常，“远”状态的值是 > 5 cm，但这会因传感器而异。

事件

ProximityChanged(distance)
当物体到设备的距离（以 cm 为单位）发生变化时触发。

方法

无
