按钮（Button）

按钮能够感知用户的点击。它的许多外观特性都可以改变，它是否可被点击 （Enabled）也可以改变。它的属性可以在设计视图或 编程视图中修改。

属性

BackgroundColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定 Button 的背景色。 如果设置了 Image，则在移除该 Image 之前看不到颜色的变化。
Enabled
指定 Button 是否处于活动状态且可点击。
FontBold
指定 Button 的文本是否使用粗体。 有些字体不支持粗体。
FontItalic
指定 Button 的文本是否使用斜体。 有些字体不支持斜体。
FontSize
指定 Button 的文本字号，以 sp（缩放无关像素）为单位。
FontTypeface
以 default、serif、sans serif、monospace 或自定义字体指定 Button 的文本字体。要添加自定义字体， 请将一个 .ttf 文件上传到项目的媒体资源中。
Height
指定 Button 的垂直高度，以像素为单位。
HeightPercent
以 Screen 的 Height 的百分比形式 指定 Button 的垂直高度。
Image
指定 Button 图像的路径。如果同时指定了 Image 和 BackgroundColor，则只有 Image 可见。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Shape
指定 Button 的形状。本属性的有效取值为 0（默认）、 1（圆角）、2（矩形）和 3（椭圆）。若使用了 Image，则 Shape 不可见。
ShowFeedback
指定当按下带有指定 Image 的 Button 时是否显示视觉反馈。
Text
指定 Button 显示的文本。
TextAlignment
指定 Button 文本的对齐方式。有效取值为： 0（正常；例如，当文字从左到右书写时为左对齐）、 1（居中），或 2（相反；例如，当文字从左到右书写时为右对齐）。
TextColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定 Button 的文本颜色。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 Button 是否在屏幕上可见。若 Button 正在显示，值为 true；若已隐藏，值为 false。
Width
指定 Button 的水平宽度，以像素为单位。
WidthPercent
以 Screen 的 Width 的百分比形式 指定 Button 的水平宽度。

事件

Click()
表示用户点击并松开了 Button。
GotFocus()
表示光标移动到 Button 上方，现在可以 点击它。
LongClick()
表示用户按住 Button 不放。
LostFocus()
表示光标从 Button 上移开，现在 不能再点击它。
TouchDown()
表示 Button 被按下。
TouchUp()
表示 Button 已被松开。

方法

控制动画 GIF 图像是否正在播放。设为 true 会从当前帧继续播放；设为 false 会在当前帧暂停。对非动画图像没有影响。
Animation
这是一种受限的动画形式，可以为图像附加少量运动类型。 允许的运动类型有 ScrollRightSlow、ScrollRight、ScrollRightFast、 ScrollLeftSlow、ScrollLeft、ScrollLeftFast 和 Stop。

图像图片呈现的旋转角度。此旋转不会显示在设计视图中，只会在设备上显示。
ScalePictureToFit
指定是否调整图像大小以匹配 ImageView 的尺寸。
Scaling
本属性决定图片如何根据 Image 的 Height 或 Width 进行缩放。按比例缩放（0）会保持图片的宽高比。按尺寸缩放（1）会匹配 Image 区域，即使宽高比发生变化。

列表框（ListView）

这是一个可视组件，用于在 Screen 中 显示由文本和图像元素组成的列表。简单的字符串列表可以用 ElementsFromString 属性设置。 包含多个字符串和/或图像的更复杂元素列表，可以用 ListData 和 ListViewLayout 属性创建。

滑动条（Slider）

本类用于显示 Slider。

Slider 是一个带有可拖动滑块的进度条。您可以触摸滑块并左右 拖动来设置滑块位置。拖动滑块时会触发 PositionChanged 事件，报告 Slider 滑块的位置。报告的 滑块位置可用于动态更新其他组件的属性， 例如某个 TextBox 的 TextBox 的 FontSize，或者 Ball 的 Radius。

Slider 使用以下默认值。不过这些值可以通过 设计视图或编程视图更改：

  • MaxValue = 50
  • ThumbPosition = 30

文本框（TextBox）

用户在文本框中输入文本。

文本框中初始的或用户输入的文本值保存在 Text 属性中。如果 Text 为空，您可以用 Hint 属性向 用户提示应输入的内容。Hint 在框中以浅色文本显示。

MultiLine 属性决定文本是否可以有多行。 对于单行文本框，用户按「完成」键时键盘会自动关闭。对于 多行文本框，应用应使用 HideKeyboard 方法 来关闭键盘，或者依赖用户按返回键。

NumbersOnly 属性限制键盘只接受数字输入。

其他属性会影响文本框的外观 （TextAlignment、BackgroundColor 等）以及它是否可用 （Enabled）。

文本框通常与 Button 组件配合使用，用户完成 文本输入后点击 Button。

如果用户输入的文本不应显示出来，请改用 PasswordTextBox。

属性

BackgroundColor
TextBox` 的背景色。您可以在设计视图或 编程视图中按名称选择颜色。默认背景色为「default」（带阴影的 3-D 外观）。
Enabled
若选中，用户可以在 TextBox 中输入文本。
FontBold
指定 TextBox 的文本是否使用粗体。 有些字体不支持粗体。
FontItalic
指定 TextBox 的文本是否使用斜体。 有些字体不支持斜体。
FontSize
指定 TextBox 的文本字号，以 sp（缩放无关像素）为单位。
FontTypeface
TextBox 的文本字体。有效取值为 0（默认）、1（serif）、2（sans serif）或 3（monospace）。
Height
指定 TextBox 的垂直高度，以像素为单位。
HeightPercent
以 Screen 的 Height 的百分比形式 指定 TextBox 的垂直高度。

给用户的 TextBox 提示。
HintColor
指定 TextBox 提示文本的颜色。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
MultiLine
若为 true，则此 TextBox 接受多行输入，输入时使用 回车键换行。对于单行文本框，键盘上显示的是「完成」键而不是回车键， 按「完成」键会隐藏键盘。对于多行文本框，应用应调用 HideKeyboard 方法 来隐藏键盘。

若为 true，则此 TextBox 只接受数字作为键盘输入。数字可以包含 小数点和可选的前导负号。这仅适用于键盘输入。即使 NumbersOnly 为 true，您仍可以使用 [Text`](#TextBox.Text) 属性将文本设置为任意内容。

WidthPercent

Web 浏览框（WebViewer）

用于浏览网页的组件。

HomeUrl 可以在设计视图或编程视图中指定。可以 设置视图在被点击时是否跟随链接，用户还可以填写网页表单。

警告：这不是一个完整的浏览器。例如，按下手机的硬件返回键 会退出应用，而不是在浏览器历史中后退。

您可以用 WebViewString 属性在应用与 运行于 WebViewer 页面中的 Javascript 代码之间通信。在应用中，您读取和设置 WebViewString。在 WebViewer 中，您引入引用 window.AppInventor 对象的 Javascript，并使用 getWebViewString() 和 setWebViewString(text) 方法。

例如，如果 WebViewer 打开的页面包含以下 Javascript 命令

 document.write("The answer is" + window.AppInventor.getWebViewString());

并且您把 WebViewString 设为「hello」，那么网页将显示

 The answer is hello.

而如果该网页包含执行以下命令的 Javascript

 windowAppInventor.setWebViewString("hello from Javascript"),

那么 WebViewString 属性的值将是

 hello from Javascript.

从 JavaScript 调用 setWebViewString 还会运行 WebViewStringChange 事件，以便块可以处理 WebViewString 属性发生变化的情况。

从 nb184a 版本开始，您可以指定以 http://localhost/ 开头的 HomeUrl，以便在 AI 伴侣（Companion）和编译后的应用中引用资源。以前，应用在编译后的应用中需要使用 file:///android_asset/，在 AI 伴侣中需要使用 /sdcard/AppInventor/assets/。 这两种方式都仍然可用，但 http://localhost/ 这种方式在 两种场景下都能用。您也可以使用「file:///appinventor_asset/」，它提供了更高的安全性， 可防止资源中 JavaScript 的异步请求外发到 网络。
