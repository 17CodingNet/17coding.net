圆（Circle）

Circle 组件用于可视化一个给定 Radius 的圆，单位为米，圆心位于 Latitude 和 Longitude。Circle 的外观可以通过诸如 FillColor、StrokeColor 和 StrokeWidth 等属性来自定义。

Circle 组件还可用于实现地理围栏（geofencing）等功能，即根据用户是否位于某个区域内来触发其他行为。将 DistanceToPoint 方法与 LocationSensor 结合使用，即可判断用户的位置是在 Circle 的内部还是外部。您可以利用该功能触发其他操作。

属性

Description
设置或获取信息窗口中显示的描述。信息窗口会在用户点击 Circle 时显示。
Draggable
设置或获取用户能否拖拽地图要素。其用法为：先长按，然后将 Circle 拖拽到新位置。
EnableInfobox
启用或禁用用户点击 Circle 时的信息框窗口显示。
FillColor
设置或获取用于填充 Circle 的颜色。
FillOpacity
设置或获取填充 Circle 所用颜色的不透明度。值为 0.0 时完全不可见，值为 1.0 时完全不透明。
Latitude
设置或获取圆心纬度（以度为单位）。正值表示赤道以北，负值表示赤道以南。要同时更新纬度和经度，请使用 SetLocation 方法。
Longitude
设置或获取圆心经度（以度为单位）。正值表示本初子午线以东，负值表示本初子午线以西。要同时更新纬度和经度，请使用 SetLocation 方法。
Radius
设置或获取圆的半径（以米为单位）。
StrokeColor
设置或获取用于勾画 Circle 的颜色。
StrokeOpacity
设置或获取 Circle 轮廓的不透明度。值为 0.0 时不可见，值为 1.0 时不透明。
StrokeWidth
设置或获取用于勾画 Circle 的线条宽度。
Title
设置或获取用户点击地图要素时显示的信息窗口标题。
Type
返回要素的类型。对于圆（Circle），返回 MapFeature.Circle（“Circle”）。
Visible
指定 Circle 是否应在屏幕上可见。值为 true 表示 Circle 正在显示，false 表示已隐藏。

事件

Click()
Click 事件在用户点击 Circle 时触发。
Drag()
Drag 事件会在用户拖拽 Circle 时，随其位置更新而触发。
LongClick()
LongClick 事件在用户按住 Circle 并松开时触发。仅当 Draggable 为 false 时才会触发，因为它与 StartDrag 使用了相同的手势。
StartDrag()
StartDrag 事件在用户按住 Circle 并保持不放，然后在屏幕上移动手指时触发。随后会依次触发 Drag 和 StopDrag 事件。
StopDrag()
StopDrag 事件在用户松开 Circle 时触发（即一次拖拽结束时）。

方法

DistanceToFeature(mapFeature,centroids)
计算 Circle 与给定的 mapFeature 之间的距离。如果 centroids 为 true，则按两个要素的质心计算距离。否则，将基于最近点计算两个要素之间的距离。此外，当 centroids 为 false 时，如果 Circle 与 mapFeature 相交或包含，则该方法返回 0。如果发生错误，该方法返回 -1。
DistanceToPoint(latitude,longitude,centroid)
计算 Circle 与给定的 latitude 和 longitude 之间的距离。如果 centroids 为 true，则从 Circle 的中心到给定点计算距离。否则，从 Circle 上距离给定点最近的点计算距离。此外，如果 centroids 为 false 且该点位于 Circle 内，则该方法返回 0。如果发生错误，将返回 -1。
HideInfobox()
隐藏 Circle 的信息框（若其可见）。否则不执行任何操作。
SetLocation(latitude,longitude)
将 Circle 的中心移动到给定的 latitude 和 longitude。此方法比分别设置 Latitude 和 Longitude 更高效。
ShowInfobox()
显示 Circle 的信息框（若其不可见）。否则，此方法不产生任何效果。即使 EnableInfobox 为 false，也可以用此方法显示信息框。

特征点集（FeatureCollection）

一个 FeatureCollection 会将一个或多个地图要素组合在一起。集合中某个要素上发生的任何事件，也会触发该集合组件中对应的事件。FeatureCollection 可以从外部资源加载，以便为 Map 填充内容。目前仅支持 GeoJSON 这一种格式。

属性

Features
获取附加到 FeatureCollection 上的要素列表（不考虑要素 Visible 属性的值）。该列表还包括通过调用 FeatureCollection 上的 FeatureFromDescription 创建的要素。
FeaturesFromGeoJSON
用包含 GeoJSON 内容的字符串填充要素集合。由于这类字符串通常很大，建议使用 Source 属性从资源文件或网络加载要素集合。
Height
指定 FeatureCollection 的垂直高度（以像素为单位）。
HeightPercent
指定 FeatureCollection 的垂直高度，其值为 Screen 的 Height 的百分比。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Source
指定用于填充要素集合的源 URL。如果要素集合不是从 URL 加载的，该值为空字符串。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 FeatureCollection 是否应在屏幕上可见。值为 true 表示 FeatureCollection 正在显示，false 表示已隐藏。
Width
指定 FeatureCollection 的水平宽度（以像素为单位）。
WidthPercent
指定 FeatureCollection 的水平宽度，其值为 Screen 的 Width 的百分比。

事件

FeatureClick(feature)
当某个要素被点击时，父级 FeatureCollection 也会接收到 FeatureClick 事件。feature 参数指明哪个子要素被点击。该事件在对应要素的 Click 事件之后运行；如果提供了 when any ... Click 事件，也会在其之后运行。
FeatureDrag(feature)
当用户拖拽某个要素时，父级 FeatureCollection 也会接收到 FeatureDrag 事件。feature 参数指明哪个子要素被拖拽。该事件在对应要素的 Drag 事件之后运行；如果提供了 when any ... Drag 事件，也会在其之后运行。
FeatureLongClick(feature)
当某个要素被长按点击时，父级 FeatureCollection 也会接收到 FeatureLongClick 事件。feature 参数指明哪个子要素被长按点击。该事件在对应要素的 LongClick 事件之后运行；如果提供了 when any ... LongClick 事件，也会在其之后运行。
FeatureStartDrag(feature)
当用户开始拖拽某个要素时，父级 FeatureCollection 也会接收到 FeatureStartDrag 事件。feature 参数指明哪个子要素被拖拽。该事件在对应要素的 StartDrag 事件之后运行；如果提供了 when any ... StartDrag 事件，也会在其之后运行。
FeatureStopDrag(feature)
当用户停止拖拽某个要素时，父级 FeatureCollection 也会接收到 FeatureStopDrag 事件。feature 参数指明哪个子要素被拖拽。该事件在对应要素的 StopDrag 事件之后运行；如果提供了 when any ... StopDrag 事件，也会在其之后运行。
GotFeatures(url,features)
GotFeatures 事件在成功从给定的 url 读取要素集合时运行。features 参数是一个要素描述列表，可使用 FeatureFromDescription 方法转换为组件。
LoadError(url,responseCode,errorMessage)
LoadError 事件在处理给定 url 处的要素集合文档时发生错误时运行。responseCode 参数将包含 HTTP 状态码，errorMessage 参数将包含详细的错误消息。

方法

FeatureFromDescription(description)
将要素描述转换为 App Inventor 地图要素。点（Point）会转换为 Marker 组件，LineString 会转换为 LineString 组件，多边形（以及多多边形）会转换为 Polygon 组件。如果要素带有属性，则会按以下映射关系转换为 App Inventor 属性：
  • description 映射为 Description
  • draggable 映射为 Draggable
  • infobox 映射为 EnableInfobox
  • fill 映射为 FillColor
  • fill-opacity 映射为 FillOpacity
  • image 映射为 ImageAsset
  • stroke 映射为 StrokeColor
  • stroke-opacity 映射为 StrokeOpacity
  • stroke-width 映射为 StrokeWidth
  • title 映射为 Title
  • visible 映射为 Visible
LoadFromURL(url)
从给定的 url 加载 GeoJSON 格式的要素集合。成功后，会触发 GotFeatures 事件，并传入给定的 url 以及由 feature 构成的列表，其中的要素按 (key, value) 对的形式从 GeoJSON 中解析而来。如果失败，则会触发 LoadError 事件，并附带相应的 HTTP 响应码和错误消息。

线（LineString）

LineString 是用于在 Map 上绘制开放、连续线段序列的组件。在设计器中为 LineString 添加新点的方法是：将任一线段的中点拖离该线条，从而引入一个新顶点。点击并拖拽顶点可将其移动到新位置。点击顶点会删除该顶点，除非只剩下两个。

属性

Description
设置或获取信息窗口中显示的描述。信息窗口会在用户点击 LineString 时显示。
Draggable
设置或获取用户能否拖拽地图要素。其用法为：先长按，然后将 LineString 拖拽到新位置。
EnableInfobox
启用或禁用用户点击 LineString 时的信息框窗口显示。
Points
LineString 中的点列表，以纬度和经度对的形式表示。
PointsFromString
使用特殊编码的字符串设置 LineString 的点，字符串格式为： [[latitude1, longitude1], [latitude2, longitude2], …]
StrokeColor
设置或获取用于勾画 LineString 的颜色。
StrokeOpacity
设置或获取 LineString 轮廓的不透明度。值为 0.0 时不可见，值为 1.0 时不透明。
StrokeWidth
设置或获取用于勾画 LineString 的线条宽度。
Title
设置或获取用户点击地图要素时显示的信息窗口标题。
Type
返回地图要素的类型。对于 LineString，返回 MapFeature.LineString（“LineString”）。
Visible
指定 LineString 是否应在屏幕上可见。值为 true 表示 LineString 正在显示，false 表示已隐藏。

事件

Click()
Click 事件在用户点击 LineString 时触发。
Drag()
Drag 事件会在用户拖拽 LineString 时，随其位置更新而触发。
LongClick()
LongClick 事件在用户按住 LineString 并松开时触发。仅当 Draggable 为 false 时才会触发，因为它与 StartDrag 使用了相同的手势。
StartDrag()
StartDrag 事件在用户按住 LineString 并保持不放，然后在屏幕上移动手指时触发。随后会依次触发 Drag 和 StopDrag 事件。
StopDrag()
StopDrag 事件在用户松开 LineString 时触发（即一次拖拽结束时）。

方法

计算 LineString 与给定的 mapFeature 之间的距离。如果 centroids 为 true，则按两个要素的质心计算距离。否则，将基于最近点计算两个要素之间的距离。此外，当 centroids 为 false 时，如果 LineString 与 mapFeature 相交或包含，则该方法返回 0。如果发生错误，该方法返回 -1。
DistanceToPoint(latitude,longitude,centroid)
计算 LineString 与给定的 latitude 和 longitude 之间的距离。如果 centroids 为 true，则从 LineString 的中心到给定点计算距离。否则，从 LineString 上距离给定点最近的点计算距离。此外，如果 centroids 为 false 且该点位于 LineString 内，则该方法返回 0。如果发生错误，将返回 -1。
HideInfobox()
隐藏 LineString 的信息框（若其可见）。否则不执行任何操作。
ShowInfobox()
显示 LineString 的信息框（若其不可见）。否则，此方法不产生任何效果。即使 EnableInfobox 为 false，也可以用此方法显示信息框。

地图（Map）

一个二维容器，在背景中渲染地图图块，并允许使用多个 Marker 元素来标识地图上的点。地图图块由 OpenStreetMap 贡献者和美国地质调查局提供，您也可以提供自定义底图 URL。

Map 组件提供了三项在 App Inventor 中调整其边界的功能。第一，提供了锁定机制，使地图可以相对于屏幕上的其他组件移动。第二，解锁后，用户可以将 Map 平移到任意位置。在新的位置上，可以点击“设定初始边界”按钮，把当前的 Map 坐标保存到其属性中。最后，如果 Map 被移动到其他位置，例如为了把 Marker 添加到屏幕之外，则可以使用“恢复到初始边界”按钮，把 Map 重新居中到起始位置。

属性

BoundingBox
设置或获取地图当前绘制视图的边界。该值是一个列表的列表，包含当前视图的西北角和东南角坐标，格式为 ((North West) (South East))。
CenterFromString
设置地图的初始中心坐标。该值以逗号分隔的十进制纬度和经度坐标对表示，例如 42.359144, -71.093612。

在代码块中，出于性能考虑，建议使用 PanTo 并传入数值型纬度和经度，而不是转换为字符串形式再使用该属性。

CustomUrl
更新地图当前所用基础图块层的自定义 URL。 例如 https://tile.openstreetmap.org/{z}/{x}/{y}.png 例如 https://example.com/geoserver/gwc/service/tms/1.0.0/workspace:layername
EnablePan
启用或禁用用户移动地图的能力。
EnableRotation
启用或禁用用于旋转地图的双指旋转手势。
EnableZoom
启用或禁用用于缩放地图的双指捏合手势。
Features
获取附加到 Map 上的要素列表（不考虑要素 Visible 属性的值）。该列表还包括通过调用 Map 上的 FeatureFromDescription 创建的要素。
Height
指定 Map 的垂直高度（以像素为单位）。
HeightPercent
指定 Map 的垂直高度，其值为 Screen 的 Height 的百分比。
Latitude
获取地图中心的纬度。要更改纬度，请使用 PanTo 方法。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
LocationSensor
使用提供的 LocationSensor 获取用户位置数据，而不是内置的位置提供程序。
Longitude
获取地图中心的经度。要更改经度，请使用 PanTo 方法。
MapType
设置或获取用于绘制地图背景的图块层。默认为 Roads。有效取值包括：
  1. Roads
  2. Aerial
  3. Terrain
  4. Custom

注意： 道路图层由 OpenStreetMap 提供，航拍和地形图层由美国地质调查局（U.S. Geological Survey）提供。

Rotation
指定地图的旋转角度，以十进制度数表示（如有）。
ScaleUnits
指定比例尺叠加层使用的单位。1（默认值）表示公制单位（km、m），2 表示英制单位（mi、ft）。
ShowCompass
指定是否在地图上显示指南针叠加层。如果硬件中存在数字指南针，指南针会随设备的方向而旋转。
ShowScale
在地图上显示比例尺参考。
ShowUser
显示或隐藏用于指示用户在 Map 上当前位置的图标。该功能的可用性和准确性取决于用户是否启用了位置服务以及有哪些位置提供程序可用。
ShowZoom
指定是否显示缩放控件。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
UserLatitude
如果启用了 ShowUser，则返回用户的纬度。
UserLongitude
如果启用了 ShowUser，则返回用户的经度。
Visible
指定 Map 是否应在屏幕上可见。值为 true 表示 Map 正在显示，false 表示已隐藏。
Width
指定 Map 的水平宽度（以像素为单位）。
WidthPercent
指定 Map 的水平宽度，其值为 Screen 的 Width 的百分比。
ZoomLevel
指定地图的缩放级别。ZoomLevel 的有效取值取决于图块提供方以及地图的纬度和经度。例如，为了节省存储图块的空间，海洋上空的缩放级别比密集的城市中心受到更多限制，因此海洋上空的取值可能是 1-7，而城市上空的取值可能是 1-20。如果缩放级别超出服务器的支持范围，图块提供方可能会返回警告图块或错误图块。

InvalidPoint(message)
InvalidPoint 事件在程序处理地理数据时遇到无效点时运行。当点的纬度或经度超出可接受范围（ [-90, 90] 和 [-180, 180]）时，该点即被视为无效。message 参数将包含该错误的说明。

LongPressAtPoint 事件在用户长按地图上某一点且不移动手指（移动手指会触发拖拽）时运行。长按的位置会通过 latitude 和 longitude 参数以地图坐标形式报告。
Ready()
Ready 事件在 Map 完成初始化并准备好接受用户交互后运行。
TapAtPoint(latitude,longitude)
TapAtPoint 事件在用户点击地图上的某一点时运行。点击的位置会通过 latitude 和 longitude 参数以地图坐标形式报告。
ZoomChange()
ZoomChange 事件在用户更改地图缩放级别时运行，例如通过双指捏合或双击进行缩放。

方法

CreateMarker(latitude,longitude)
创建一个新的 Marker，将其放在 Map 上指定的 latitude 和 longitude 处。
FeatureFromDescription(description)
将要素描述转换为 App Inventor 地图要素。点（Point）会转换为 Marker 组件，LineString 会转换为 LineString 组件，多边形（以及多多边形）会转换为 Polygon 组件。如果要素带有属性，则会按以下映射关系转换为 App Inventor 属性：
  • description 映射为 Description
  • draggable 映射为 Draggable
  • infobox 映射为 EnableInfobox
  • fill 映射为 FillColor
  • fill-opacity 映射为 FillOpacity
  • image 映射为 ImageAsset
  • stroke 映射为 StrokeColor
  • stroke-opacity 映射为 StrokeOpacity
  • stroke-width 映射为 StrokeWidth
  • title 映射为 Title
  • visible 映射为 Visible
LoadFromURL(url)
从给定的 url 加载 GeoJSON 格式的要素集合。成功后，会触发 GotFeatures 事件，并传入给定的 url 以及由 feature 构成的列表，其中的要素按 (key, value) 对的形式从 GeoJSON 中解析而来。如果失败，则会触发 LoadError 事件，并附带相应的 HTTP 响应码和错误消息。
PanTo(latitude,longitude,zoom)
将地图中心平移到给定的纬度和经度，并把缩放级别调整为指定的缩放值。
Save(path)
将 Map 上的要素保存为指定路径下的 GeoJSON 文件。

标记（Marker）

Marker 组件用于标记 Map 上的点，例如建筑物或其他兴趣点。Marker 可以通过多种方式自定义，例如使用应用资源中的自定义图像，或更改 Marker FillColor。Marker 也可以动态创建：调用 Map 的 CreateMarker 方法创建，并使用 “任意组件” 块对其进行配置。

属性

AnchorHorizontal
设置或获取 Marker 中心相对于其图像的水平偏移量。有效取值为：1 （左），2 （右），或 3 （居中）。
AnchorVertical
设置或获取 Marker 中心相对于其图像的垂直偏移量。有效取值为：1 （上），2 （中），或 3 （下）。
Description
设置或获取信息窗口中显示的描述。信息窗口会在用户点击 Marker 时显示。
Draggable
设置或获取用户能否拖拽地图要素。其用法为：先长按，然后将 Marker 拖拽到新位置。
EnableInfobox
启用或禁用用户点击 Marker 时的信息框窗口显示。
FillColor
设置或获取用于填充 Marker 的颜色。
FillOpacity
设置或获取填充 Marker 所用颜色的不透明度。值为 0.0 时完全不可见，值为 1.0 时完全不透明。
Height
指定 Marker 的垂直高度（以像素为单位）。
HeightPercent
指定 Marker 的垂直高度，其值为 Screen 的 Height 的百分比。
ImageAsset
指定 Marker 显示的图像。如果设为空字符串“”，则使用默认的标记图标。
Latitude
设置或获取 Marker 的纬度（以度为单位），正值表示赤道以北，负值表示赤道以南。要同时更新 Latitude 和 Longitude，请使用 SetLocation 方法。
Longitude
设置或获取 Marker 的经度（以度为单位），正值表示本初子午线以东，负值表示本初子午线以西。要同时更新 Latitude 和 Longitude，请使用 SetLocation 方法。
StrokeColor
设置或获取用于勾画 Marker 的颜色。
StrokeOpacity
设置或获取 Marker 轮廓的不透明度。值为 0.0 时不可见，值为 1.0 时不透明。
StrokeWidth
设置或获取用于勾画 Marker 的线条宽度。
Title
设置或获取用户点击地图要素时显示的信息窗口标题。
Type
返回地图要素的类型。对于 Marker，返回文本“Marker”。
Visible
指定 Marker 是否应在屏幕上可见。值为 true 表示 Marker 正在显示，false 表示已隐藏。
Width
指定 Marker 的水平宽度（以像素为单位）。
WidthPercent
指定 Marker 的水平宽度，其值为 Screen 的 Width 的百分比。

事件

Click()
Click 事件在用户点击 Marker 时触发。
Drag()
Drag 事件会在用户拖拽 Marker 时，随其位置更新而触发。
LongClick()
LongClick 事件在用户按住 Marker 并松开时触发。仅当 Draggable 为 false 时才会触发，因为它与 StartDrag 使用了相同的手势。
StartDrag()
StartDrag 事件在用户按住 Marker 并保持不放，然后在屏幕上移动手指时触发。随后会依次触发 Drag 和 StopDrag 事件。
StopDrag()
StopDrag 事件在用户松开 Marker 时触发（即一次拖拽结束时）。

方法

BearingToFeature(mapFeature,centroids)
返回从 Marker 到给定地图要素的方位角（以度为单位，自正北方向起算）。如果 centroids 参数为 true，则方位角指向该地图要素的中心；否则，将计算到该要素中距离 Marker 最近的点的方位角。
BearingToPoint(latitude,longitude)
返回从 Marker 到给定的 latitude 和 longitude 的方位角（以度为单位，自正北方向起算）。
DistanceToFeature(mapFeature,centroids)
计算 Marker 与给定的 mapFeature 之间的距离。如果 centroids 为 true，则按两个要素的质心计算距离。否则，将基于最近点计算两个要素之间的距离。此外，当 centroids 为 false 时，如果 Marker 与 mapFeature 相交或包含，则该方法返回 0。如果发生错误，该方法返回 -1。
DistanceToPoint(latitude,longitude)
计算 Marker 与 latitude、longitude 点之间的距离（以米为单位）。
HideInfobox()
隐藏 Marker 的信息框（若其可见）。否则不执行任何操作。
SetLocation(latitude,longitude)
设置 Marker 的位置。
ShowInfobox()
显示 Marker 的信息框（若其不可见）。否则，此方法不产生任何效果。即使 EnableInfobox 为 false，也可以用此方法显示信息框。

导航（Navigation）

Navigation 组件使用名为 OpenRouteService 的服务来生成两个位置之间的路线。要使该组件正常工作，您必须提供来自该服务的有效 API 密钥。

属性

ApiKey
Open Route Service 的 API 密钥。可在 https://openrouteservice.org。
EndLatitude
终点位置的纬度。
EndLocation
设置终点位置。
EndLongitude
终点位置的经度。
Language
文字导航指示所用的语言。默认值为“en”，表示英语。
ResponseContent
服务器返回的原始响应。除 GotDirections 事件提供的内容之外，还可通过它访问更多细节。
StartLatitude
起点位置的纬度。
StartLocation
设置起点位置。
StartLongitude
起点位置的经度。
TransportationMethod
用于确定路线的交通方式。有效选项包括：
  • foot-walking：基于步行路径的路线
  • driving-car：基于车辆行驶路径的路线
  • cycling-regular：基于自行车路径的路线
  • wheelchair：基于轮椅无障碍路径的路线

事件

GotDirections(directions,points,distance,duration)
表示请求已完成并已返回数据的事件。提供以下参数：
  • directions：文字导航指示的列表，例如“Turn left at Massachusetts Avenue”。
  • points：（latitude, longitude）点构成的列表，表示所要走的路径。可以将其传给 LineString 的 Points，以在 Map 上绘制该线条。
  • distance：路线的估计距离，单位为米。
  • duration：路线的估计时长，单位为秒。

方法

RequestDirections()
使用 StartLatitude、StartLongitude、EndLatitude 和 EndLongitude 的值向路径规划服务请求路线。成功后，将运行 GotDirections 事件块。如果发生错误，错误将通过 Screen's ErrorOccurred 事件报告。

多边形（Polygon）

Polygon 用于在 Map 上围出任意二维区域。Polygon 可用于绘制边界，例如校园、城市或国家。Polygon 初始时为基本的三角形。将多边形的中点拖离边缘可以创建新顶点。点击顶点会移除该顶点，但任何时刻都必须至少存在 3 个顶点。

属性

Description
设置或获取信息窗口中显示的描述。信息窗口会在用户点击 Polygon 时显示。
Draggable
设置或获取用户能否拖拽地图要素。其用法为：先长按，然后将 Polygon 拖拽到新位置。
EnableInfobox
启用或禁用用户点击 Polygon 时的信息框窗口显示。
FillColor
设置或获取用于填充 Polygon 的颜色。
FillOpacity
设置或获取填充 Polygon 所用颜色的不透明度。值为 0.0 时完全不可见，值为 1.0 时完全不透明。
HolePoints
指定 Polygon 中孔洞的点。HolePoints 属性是一个由列表组成的列表，其中每个子列表包含表示一个孔洞的 (latitude, longitude) 点。
HolePointsFromString
指定 Polygon 的孔洞（由 GeoJSON 字符串给出）。与 HolePoints 不同，按照 GeoJSON 规范的规定，每个点的经度排在纬度之前。
Points
指定用于绘制 Polygon 的点。这些点以包含纬度和经度值的列表的列表形式给出，例如 [[lat1, long1], [lat2, long2], ...]。
PointsFromString
指定 Polygon 的点（由 GeoJSON 字符串给出）。与 Points 不同，该属性要求点中经度在前、纬度在后。
StrokeColor
设置或获取用于勾画 Polygon 的颜色。
StrokeOpacity
设置或获取 Polygon 轮廓的不透明度。值为 0.0 时不可见，值为 1.0 时不透明。
StrokeWidth
设置或获取用于勾画 Polygon 的线条宽度。
Title
设置或获取用户点击地图要素时显示的信息窗口标题。
Type
返回要素的类型。对于多边形（polygon），返回 MapFeature.Polygon（“Polygon”）。
Visible
指定 Polygon 是否应在屏幕上可见。值为 true 表示 Polygon 正在显示，false 表示已隐藏。

事件

Click()
Click 事件在用户点击 Polygon 时触发。
Drag()
Drag 事件会在用户拖拽 Polygon 时，随其位置更新而触发。
LongClick()
LongClick 事件在用户按住 Polygon 并松开时触发。仅当 Draggable 为 false 时才会触发，因为它与 StartDrag 使用了相同的手势。
StartDrag()
StartDrag 事件在用户按住 Polygon 并保持不放，然后在屏幕上移动手指时触发。随后会依次触发 Drag 和 StopDrag 事件。
StopDrag()
StopDrag 事件在用户松开 Polygon 时触发（即一次拖拽结束时）。

方法

Centroid()
获取 Polygon 的质心，以 (latitude, longitude) 对的形式返回。
DistanceToFeature(mapFeature,centroids)
计算 Polygon 与给定的 mapFeature 之间的距离。如果 centroids 为 true，则按两个要素的质心计算距离。否则，将基于最近点计算两个要素之间的距离。此外，当 centroids 为 false 时，如果 Polygon 与 mapFeature 相交或包含，则该方法返回 0。如果发生错误，该方法返回 -1。
DistanceToPoint(latitude,longitude,centroid)
计算 Polygon 与给定的 latitude 和 longitude 之间的距离。如果 centroids 为 true，则从 Polygon 的中心到给定点计算距离。否则，从 Polygon 上距离给定点最近的点计算距离。此外，如果 centroids 为 false 且该点位于 Polygon 内，则该方法返回 0。如果发生错误，将返回 -1。
HideInfobox()
隐藏 Polygon 的信息框（若其可见）。否则不执行任何操作。
ShowInfobox()
显示 Polygon 的信息框（若其不可见）。否则，此方法不产生任何效果。即使 EnableInfobox 为 false，也可以用此方法显示信息框。
