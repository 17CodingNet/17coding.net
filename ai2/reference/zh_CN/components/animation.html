球（Ball）

一个圆形的“精灵”，可以放置到 Canvas 上，它可以在画布上响应触摸和拖拽， 与其他精灵（ImageSprite 和其他 Ball）以及 Canvas 的边缘交互，并根据自身的属性值移动。

例如，要让一个 Ball 每 500 毫秒（半秒）向 Canvas 的顶部移动 4 个像素， 您应将 Speed 属性设为 4[像素]，将 Interval 属性设为 500[毫秒]，将 Heading 属性设为 90[度]，并将 Enabled 属性设为 true。这些属性 以及它的其他属性都可以随时修改。

Ball 与 ImageSprite 的区别在于，后者可以从图像文件获得外观， 而 Ball 的外观只能通过改变其 PaintColor 和 Radius 属性来改变。

属性

Enabled
控制当速度非零时 Ball 是否移动。
Heading
Ball 在正 x 轴上方以度为单位的方向。零度朝向屏幕右侧； 90 度朝向屏幕顶部。
Interval
更新 Ball 位置的时间间隔，以毫秒为单位。例如，如果 Interval 为 50 而 Speed 为 10，则 Ball 每 50 毫秒 移动 10 个像素。
OriginAtCenter
x 和 y 坐标应表示 Ball 的中心 （true），还是表示其左边缘和上边缘（false）。
PaintColor
Ball 的颜色。
Radius
从 Ball 中心到其边缘的距离。
Speed
Ball 移动的速度。如果 Enabled 为 true，则 Ball 每隔 Interval 毫秒移动这么多像素。
Visible
设置精灵是否可见。
X
Ball 的水平坐标，随着 Ball 向右移动而增大。如果属性 OriginAtCenter 为 true，则该坐标是 Ball 中心的坐标； 否则，它是 Ball 最左侧点的坐标。
Y
Ball 的垂直坐标，随着 Ball 向下移动而增大。如果属性 OriginAtCenter 为 true，则该坐标是 Ball 中心的坐标， 否则，它是 Ball 最上方点的坐标。
Z
Ball 相对于其他 Ball 和 ImageSprite 的分层方式，编号较大的层位于编号较小的层前面。

事件

CollidedWith(other)
当两个已启用的精灵（Ball 或 ImageSprite）发生碰撞时 调用的事件处理程序。请注意，与旋转后的 ImageSprite 进行碰撞检测时， 目前是按未旋转的位置来检查的。因此，对于旋转后的细高或扁宽的 精灵，碰撞检测将不准确。
Dragged(startX,startY,prevX,prevY,currentX,currentY)
Drag（拖动）事件的事件处理程序。在所有调用中，起始坐标 都是屏幕最初被触摸的位置，而“当前”坐标则描述当前线段的 终点。在一次给定的拖动中，首次调用时的“上一个”坐标与 起始坐标相同；此后，它们就是上一次调用中的“当前”坐标。 请注意，除非专门调用 MoveTo，否则 Ball 不会因响应 Dragged 事件而实际移动。
EdgeReached(edge)
当 Ball 到达屏幕的某个 edge 时调用的事件处理程序。 如果随后用该边缘调用 Bounce，精灵看起来就会从 所到达的边缘弹回。此处的 edge 用一个整数表示八个 方向之一：北(1)、东北(2)、东(3)、东南(4)、南(-1)、西南(-2)、西(-3)、 西北(-4)。
Flung(x,y,speed,heading,xvel,yvel)
当在精灵上做出划动（快速滑动）手势时：提供 划动起点的 (x,y) 位置，相对于画布的 左上角。还提供划动的速度（像素/毫秒）和方向 （-180 到 180 度），以及划动向量的 x 速度和 y 速度 分量。
NoLongerCollidingWith(other)
表示一对精灵不再碰撞的事件。
TouchDown(x,y)
当用户开始触摸精灵（手指放在精灵上并 保持不动）时：提供触摸点的 (x,y) 位置，相对于 画布的左上角。
TouchUp(x,y)
当用户停止触摸精灵（在 TouchDown 事件之后 抬起手指）时：提供触摸点的 (x,y) 位置，相对于 画布的左上角。
Touched(x,y)
当用户触摸精灵并随即抬起手指时：提供 触摸点的 (x,y) 位置，相对于画布的左上角。

方法

Bounce(edge)
使此 Ball 像撞墙一样弹回。对于正常的弹跳，edge 参数应 使用 EdgeReached 返回的值。
CollidingWith(other)
指示此 Ball 与传入的 other 精灵之间是否已记录碰撞。
MoveIntoBounds()
如果精灵的一部分超出边界，则将其移回边界内， 否则不产生任何效果。如果精灵太宽而无法放入 画布，则将精灵的左侧与画布的左侧对齐。如果精灵太高而无法放入 画布，则将精灵的顶部与画布的顶部对齐。
MoveTo(x,y)
设置 Ball 的 x 和 y 坐标。如果 OriginAtCenter 为 true， 则 Ball 的中心将放置在此处。否则，Ball 的左上边缘 将放置在指定坐标处。
MoveToPoint(coordinates)
移动 Ball，使其原点位于指定的 x 和 y 坐标处。
PointInDirection(x,y)
旋转此 Ball，使其指向坐标为 (x, y) 的点。
PointTowards(target)
旋转此 Ball，使其指向给定的 target 精灵。新的方向将平行 于连接两个精灵原点的直线。

画布（Canvas）

一个二维的、可感知触摸的矩形面板，可以在其上绘图， 也可以在其中移动精灵。

Canvas 的 BackgroundColor、PaintColor、BackgroundImage、 Width 和 Height 既可以在设计视图中设置，也可以在 块编辑器中设置。Width 和 Height 以像素为单位，且必须为正数。

Canvas 上的任何位置都可以用一对 (X, Y) 值来表示，其中

  • X 是距离 Canvas 左边缘的像素数
  • Y 是距离 Canvas 上边缘的像素数

有些事件可以告知 Canvas 何时被触摸、触摸点在何处，或者某个 精灵（ImageSprite 或 Ball）何时被拖动。还有一些方法可以 绘制点、线、圆、形状、弧线和文本。

属性

BackgroundColor
以 alpha-red-green-blue（透明度-红-绿-蓝） 整数指定 Canvas 的背景色，即 0xAARRGGBB。alpha 为 00 表示完全透明，FF 表示不透明。 只有在没有背景图片时才会显示背景色。
BackgroundImage
指定包含 Canvas 背景图片的文件名。
BackgroundImageinBase64
以 Base64 格式设置背景图片。这要求 API 级别 >= 8。对于 API 级别低于 8 的设备，设置此项最终会得到一个空背景。
ExtendMovesOutsideCanvas
决定移动是否可以延伸到画布边界之外。 默认值为 false。通常应设为 false，提供此属性是为了向后兼容。
FontSize
指定在画布上绘制的文本的字号。
Height
指定 Canvas 的垂直高度，以像素为单位。
HeightPercent
以 Screen’s Height 的百分比形式 指定 Canvas 的垂直高度。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
LineWidth
指定在画布上绘制的线条的宽度。
PaintColor
以 alpha-red-green-blue 整数指定画笔颜色， 即 0xAARRGGBB。alpha 为 00 表示完全 透明，FF 表示不透明。
TapThreshold
指定用于区分拖动与点击的移动阈值。
TextAlignment
指定画布文本的对齐方式：居中、正常 （从 DrawText 或 DrawTextAtAngle 中指定的点开始）， 或反向（在 DrawText 或 DrawTextAtAngle 中指定的点结束）。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 Canvas 是否应在屏幕上可见。若 Canvas 正在显示，值为 true；若已隐藏，值为 false。
Width
指定 Canvas 的水平宽度，以像素为单位。
WidthPercent
以 Screen’s Width 的百分比形式 指定 Canvas 的水平宽度。

事件

Dragged(startX,startY,prevX,prevY,currentX,currentY,draggedAnySprite)
当用户从一点 (prevX, prevY) 拖动到 另一点 (x, y) 时。其中 (startX, startY) 表示用户 最初触摸屏幕的位置，而“draggedAnySprite”表示是否 有精灵正在被拖动。
Flung(x,y,speed,heading,xvel,yvel,flungSprite)
当在画布上做出划动（快速滑动）手势时：提供 划动起点的 (x,y) 位置，相对于画布的 左上角。还提供划动的速度（像素/毫秒）和方向 （-180 到 180 度），以及划动向量的 x 速度和 y 速度 分量。“flungSprite”的值为 true 表示在划动手势的 起点附近有精灵。
TouchDown(x,y)
当用户开始触摸画布（手指放在画布上并 保持不动）时：提供触摸点的 (x,y) 位置，相对于 画布的左上角。
TouchUp(x,y)
当用户停止触摸画布（在 TouchDown 事件之后 抬起手指）时：提供触摸点的 (x,y) 位置，相对于 画布的左上角。
Touched(x,y,touchedAnySprite)
当用户触摸画布并随即抬起手指时：提供 触摸点的 (x,y) 位置，相对于画布的左上角。如果同一次触摸也碰到了 精灵，则 TouchedAnySprite 为 true，否则为 false。

方法

Clear()
清除画布，如果提供过背景图片， 则保留该背景图片。
DrawArc(left,top,right,bottom,startAngle,sweepAngle,useCenter,fill)
在 Canvas 上绘制一条弧线，即从指定的椭圆（由 left、top、right 和 bottom 指定）上绘制一段弧。 方向指向右侧时起始角为 0，顺时针旋转时角度增大。 当 useCenter 为 true 时，将绘制扇形而不是弧线。 当 fill 为 true 时，将绘制填充的弧线（或扇形），而不仅仅是轮廓。
DrawCircle(centerX,centerY,radius,fill)
在画布上以给定坐标为中心，绘制一个半径为给定值的圆（实心）。
DrawLine(x1,y1,x2,y2)
在画布上给定坐标之间绘制一条线。
DrawPoint(x,y)
在画布上给定坐标处绘制一个点。
DrawShape(pointList,fill)
在画布上绘制一个形状。 pointList 应为包含子列表的列表，每个子列表由两个数字组成，表示一个坐标。 第一个点和最后一个点不必相同，例如 ((x1 y1) (x2 y2) (x3 y3))。 当 fill 为 true 时，该形状将被填充。
DrawText(text,x,y)
使用 FontSize 和 TextAlignment 属性的值，相对于指定坐标 绘制指定的文本。
DrawTextAtAngle(text,x,y,angle)
使用 FontSize 和 TextAlignment 属性的值，从指定坐标开始 以指定角度绘制指定的文本。
GetBackgroundPixelColor(x,y)
获取给定像素的颜色，忽略精灵。
GetPixelColor(x,y)
获取给定像素的颜色，包括精灵。
Save()
将此 Canvas 的图片保存到设备的外部存储器。 如果发生错误，将调用屏幕的 ErrorOccurred 事件。
SaveAs(fileName)
将此 Canvas 的图片以文件名 fileName 保存到设备的外部存储器。 fileName 必须以“.jpg”“.jpeg”或“.png”结尾 （这决定文件类型：JPEG 或 PNG）。
SetBackgroundPixelColor(x,y,color)
设置给定像素的颜色。如果 坐标超出边界，则不会产生任何效果。

精灵（ImageSprite）

一个“精灵”，可以放置到 Canvas 上，它可以在画布上响应触摸和拖拽， 与其他精灵（Ball 和其他 ImageSprite）以及 Canvas 的边缘交互，并根据自身的属性值移动。它的外观就是其 Picture 属性中指定的图像（除非其 Visible 属性为 false）。

例如，要让一个 ImageSprite 每 1000 毫秒（一秒）向左移动 10 个像素， 您应将 Speed 属性设为 10[像素]，将 Interval 属性设为 1000[毫秒]，将 Heading 属性设为 180[度]，并将 Enabled 属性设为 true。当 Rotates 属性为 true 时，精灵的图像会随精灵方向的变化而旋转。 与旋转后的精灵进行碰撞检测时，目前是按精灵未旋转的位置 来检查的，因此对于旋转后的细高或扁宽的精灵，碰撞检测将不准确。 精灵的任何属性都可以在程序控制下随时修改。

属性

Animated
控制动画 GIF 图像是否正在播放。设为 true 会从当前帧继续播放；设为 false 会在当前帧暂停。对非动画图像没有影响。
Enabled
控制当速度非零时 ImageSprite 是否移动。
Heading
ImageSprite 在正 x 轴上方以度为单位的方向。零度朝向屏幕右侧； 90 度朝向屏幕顶部。
Height
ImageSprite 的高度，以像素为单位。
Interval
更新 ImageSprite 位置的时间间隔，以毫秒为单位。例如，如果 Interval 为 50 而 Speed 为 10，则 ImageSprite 每 50 毫秒移动 10 个像素。
MarkOrigin
使用可拖动的标记来标记 ImageSprite 的原点。
OriginX
原点相对于左边缘的水平单位坐标。允许的取值为 [0, 1]。 0.0 表示原点位于左边缘，0.5 表示原点位于 中间，1.0 表示原点位于右边缘。
OriginY
原点相对于上边缘的垂直单位坐标。允许的取值为 [0, 1]。 0.0 表示原点位于上边缘，0.5 表示原点位于 中间，1.0 表示原点位于下边缘。
Picture
指定精灵图片的路径。
Rotates
如果为 true，则精灵图像会随精灵方向的变化而旋转。如果为 false，则精灵图像 在精灵改变方向时不旋转。精灵围绕其原点旋转。
Speed
ImageSprite 移动的速度。如果 Enabled 为 true，则 ImageSprite 每隔 Interval 毫秒移动这么多像素。
Visible
设置精灵是否可见。
Width
ImageSprite 的宽度，以像素为单位。
X
ImageSprite 原点的水平坐标，随着 ImageSprite 向右移动而增大。
Y
ImageSprite 原点的垂直坐标，随着 ImageSprite 向下移动而增大。
Z
ImageSprite 相对于其他 Ball 和 ImageSprite 的分层方式，编号较大的层位于编号较小的层前面。

CollidedWith(other)
当两个已启用的精灵（Ball 或 ImageSprite）发生碰撞时 调用的事件处理程序。请注意，与旋转后的 ImageSprite 进行碰撞检测时， 目前是按未旋转的位置来检查的。因此，对于旋转后的细高或扁宽的 精灵，碰撞检测将不准确。
Dragged(startX,startY,prevX,prevY,currentX,currentY)
Drag（拖动）事件的事件处理程序。在所有调用中，起始坐标 都是屏幕最初被触摸的位置，而“当前”坐标则描述当前线段的 终点。在一次给定的拖动中，首次调用时的“上一个”坐标与 起始坐标相同；此后，它们就是上一次调用中的“当前”坐标。 请注意，除非专门调用 MoveTo，否则 ImageSprite 不会 因响应 Dragged 事件而实际移动。
EdgeReached(edge)
当 ImageSprite 到达屏幕的某个 edge 时调用的事件处理程序。 如果随后用该边缘调用 Bounce，精灵看起来就会从 所到达的边缘弹回。此处的 edge 用一个整数表示八个 方向之一：北(1)、东北(2)、东(3)、东南(4)、南(-1)、西南(-2)、西(-3)、 西北(-4)。
Flung(x,y,speed,heading,xvel,yvel)
当在精灵上做出划动（快速滑动）手势时：提供 划动起点的 (x,y) 位置，相对于画布的 左上角。还提供划动的速度（像素/毫秒）和方向 （-180 到 180 度），以及划动向量的 x 速度和 y 速度 分量。
NoLongerCollidingWith(other)
表示一对精灵不再碰撞的事件。
TouchDown(x,y)
当用户开始触摸精灵（手指放在精灵上并 保持不动）时：提供触摸点的 (x,y) 位置，相对于 画布的左上角。
TouchUp(x,y)
当用户停止触摸精灵（在 TouchDown 事件之后 抬起手指）时：提供触摸点的 (x,y) 位置，相对于 画布的左上角。
Touched(x,y)
当用户触摸精灵并随即抬起手指时：提供 触摸点的 (x,y) 位置，相对于画布的左上角。

方法

Bounce(edge)
使此 ImageSprite 像撞墙一样弹回。对于正常的弹跳，edge 参数应 使用 EdgeReached 返回的值。
CollidingWith(other)
指示此 ImageSprite 与传入的 other 精灵之间是否已记录碰撞。
MoveIntoBounds()
如果精灵的一部分超出边界，则将其移回边界内， 否则不产生任何效果。如果精灵太宽而无法放入 画布，则将精灵的左侧与画布的左侧对齐。如果精灵太高而无法放入 画布，则将精灵的顶部与画布的顶部对齐。
MoveTo(x,y)
移动 ImageSprite，使其原点位于指定的 x 和 y 坐标处。
MoveToPoint(coordinates)
移动 ImageSprite，使其原点位于指定的 x 和 y 坐标处。
PointInDirection(x,y)
旋转此 ImageSprite，使其指向坐标为 (x, y) 的点。
PointTowards(target)
旋转此 ImageSprite，使其指向给定的 target 精灵。新的方向将平行 于连接两个精灵原点的直线。
ResetAnimation()
将动画 GIF 图像的动画重置到第一帧。如果动画正在播放，它会从头继续播放；如果已暂停，则保持暂停在第一帧。
