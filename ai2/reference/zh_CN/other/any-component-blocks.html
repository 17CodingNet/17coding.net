任意组件块

编写应用时有一个常见原则叫“不要重复自己”（Don’t Repeat Yourself，DRY）。与其写一大堆重复的代码（比如靠复制粘贴），不如改用一类特殊的块——“任意组件”（Any Component）块。

那么“任意组件”块到底是什么呢？每一个组件块，例如 set Button1.Text to，都由三部分组成：(1) 被修改的组件（Button1）；(2) 被操作的组件属性（set ….Text to）；(3) 输入（如果有的话）。您编写应用时，从块抽屉里拖出来的块通常都指定了某一个具体的组件。但如果您想对许多同一类型的不同组件执行同一个操作，该怎么办呢？一种办法是按需把每个块复制粘贴很多次，但随着应用规模扩大，这样做就很难编辑了。这时，如果能用一个可替换的组件来代表某一个具体组件，就会方便很多。“任意组件”块正是为此而设。它们不把块限定在某个具体组件上，而是允许您输入同一类型的任意一个组件，让代码更通用。例如，您可以建立一个按钮的列表，然后用 for-each（遍历）循环一次性更新它们的所有属性，如下所示：

组件块的主要三种类型，即事件、方法和属性，都有对应的“任意组件”块。

属性

属性类的“任意组件”块是所有任意组件块中最简单的一种。属性读取块（如下图所示）接受一个组件，并返回该组件上指定属性的值。属性设置块则多接受一个参数，即该属性的新值。

任意组件的方法块用法与属性读取块、设置块类似。对于组件上的某个方法，对应的任意组件块会接受一个组件以及该方法所需的全部参数。该块的输出与具体的组件方法块（如果有输出的话）相同。例如，下面是一个方法块，用来计算地图（Map）上某个标记（Marker）到用户当前位置的距离。

事件

任意组件的事件块是任意组件块中最复杂的一种。对于某个事件，对应的任意组件事件块会在原有的事件参数列表（如果有）之外，再增加两个参数：component 和 notAlreadyHandled。component 参数是触发该事件的那个组件，例如 Button。如果没有其他事件块专门处理 component 上的该事件，那么 notAlreadyHandled 参数就为 true。

看看下面这段事件处理的伪代码，就能了解它的工作机制：

  1. 某个事件发生，例如用户点击了名为 Button1 的按钮。
  2. component 被初始化为 Button1。
  3. notAlreadyHandled 被初始化为 true。
  4. App Inventor 检查是否存在 when Button1.Click。
  5. 如果找到了该事件块：
    1. 运行该事件块中的代码。
    2. notAlreadyHandled 被设为 false。
  6. App Inventor 检查是否存在 when any Button.Click。
  7. 如果找到了该任意组件事件块，就运行该事件块中的代码，并把 component 和 notAlreadyHandled 传给它。

提示与技巧

用任意组件块可以做很多事情。下面是一些提示与技巧，帮您充分发挥任意组件块的作用。

组件列表

您可以用全局变量把组件放进 make a list（建立列表）中。这样就可以通过一个列表轻松引用大量组件，并用 for-each（遍历）块对它们统一做修改。

图 4. 全局变量 listOfButtons 被设为一个由按钮组件构成的列表。

互换块

您可以通过块的右键（上下文）菜单中的“Make Generic”和“Make Specific”菜单项，在针对具体组件的块与等价的任意组件块之间来回切换。“Make Generic”（类代码）会把针对具体组件的块，例如 set Button1.Enabled to，转换成任意组件块，例如带有对应组件块（如 Button1）的 set Button.Enabled of component。要使用“Make Specific”（转为组件代码块）菜单项，“of component”插槽中必须填入一个具体的组件（如 Button1），而不能是其他类型的块。该功能适用于属性设置块、属性读取块和方法块。

图 5. 演示如何用右键（上下文）菜单把块从具体版本转换为通用版本。

任意组件事件

与把属性和方法转成任意组件版本的操作不同，用“Make Generic”（类代码）把某个组件的事件处理程序改成任意组件事件是单向操作（不过仍可以用“撤消”选项撤销）。使用该功能时，所有对该组件的引用都会被替换成任意组件版本。


图 6. 上：一个 when Button1.Click 事件，它会修改 Button1 的若干属性。下：使用“Make Generic”菜单项（下图）之后，when Button1.Click 事件被替换为 when any Button.Click 事件，所有引用 Button1 的块都被替换为 component。
