摄像机（Camcorder）

用于使用设备摄像机录制视频的组件。录制完成后，手机上保存该片段的文件名 可作为 AfterRecording 事件的参数获取。 例如，可以用该文件名设置 VideoPlayer 组件的 Source 属性。

属性

无

事件

AfterRecording(clip)
表示已用摄像机录制了一段视频，并提供所存视频的路径。

方法

RecordVideo()
录制一段视频，然后引发 AfterRecording 事件。

照相机（Camera）

使用照相机组件在手机上拍照。

Camera 是一个非可视组件，它使用设备的照相机拍照。拍照后， 手机上保存该照片的文件路径可作为 AfterPicture 事件的参数获取。例如，该路径可用作 Picture 属性，供 Image 组件使用。

属性

无

事件

AfterPicture(image)
拍照后调用。文本参数 image 是可用于在手机上 定位该图像的路径。

方法

TakePicture()
拍摄一张照片，然后引发 AfterPicture 事件。

文件选框（FilePicker）

FilePicker 组件是一个类似按钮的组件，用户点击它时 会提示用户从系统中选择一个文件。也可以通过调用它的 Open 方法 以编程方式打开该选择器。使用 FilePicker 需要 Android 4.4 或更高版本，或 iOS 11 或更高版本。

属性

Action
设置 FilePicker 的期望动作。取值之一：
  • 选择文件（Pick Existing File）：打开已有文件
  • 选择目录（Pick Directory）：打开已有目录
  • 新建文件（Pick New File）：创建新文件用于保存
BackgroundColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定 FilePicker 的背景色。 如果设置了 Image，则在移除该 Image 之前看不到颜色的变化。
Enabled
指定 FilePicker 是否处于活动状态且可点击。
FontBold
指定 FilePicker 的文本是否使用粗体。 有些字体不支持粗体。
FontItalic
指定 FilePicker 的文本是否使用斜体。 有些字体不支持斜体。
FontSize
指定 FilePicker 的文本字号，以 sp（缩放无关像素）为单位。
FontTypeface
以 default、serif、sans serif、monospace 或自定义字体指定 FilePicker 的文本字体。要添加自定义字体， 请将一个 .ttf 文件上传到项目的媒体资源中。
Height
指定 FilePicker 的垂直高度，以像素为单位。
HeightPercent
以 Screen 的 Height 的百分比形式 指定 FilePicker 的垂直高度。
Image
指定 FilePicker 图像的路径。如果同时指定了 Image 和 BackgroundColor，则只有 Image 可见。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
MimeType
设置选择文件时所需的 MIME 类型。
Selection
返回选中的文件，可能表示为 content URI。
Shape
指定 FilePicker 的形状。本属性的有效取值为 0（默认）、 1（圆角）、2（矩形）和 3（椭圆）。若使用了 Image，则 Shape 不可见。
ShowFeedback
指定当按下带有指定 Image 的 FilePicker 时是否显示视觉反馈。
Text
指定 FilePicker 显示的文本。
TextAlignment
指定 FilePicker 文本的对齐方式。有效取值为： 0（正常；例如，当文字从左到右书写时为左对齐）、 1（居中），或 2（相反；例如，当文字从左到右书写时为右对齐）。
TextColor
以 alpha-red-green-blue（透明度-红-绿-蓝）整数指定 FilePicker 的文本颜色。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 FilePicker 是否在屏幕上可见。若 FilePicker 正在显示，值为 true； 若已隐藏，值为 false。
Width
指定 FilePicker 的水平宽度，以像素为单位。
WidthPercent
以 Screen 的 Width 的百分比形式 指定 FilePicker 的水平宽度。

事件

AfterPicking()
FilePicker 活动返回结果并填好相关属性后 要引发的事件。
BeforePicking()
当 FilePicker 被点击，或用 Open 方法显示选择器时要引发的事件。此事件在选择器显示之前发生， 可用于在显示选择器之前做好准备工作。
GotFocus()
表示光标移动到 FilePicker 上方，现在可以 点击它。
LostFocus()
表示光标从 FilePicker 上移开，现在 不能再点击它。
TouchDown()
表示 FilePicker 被按下。
TouchUp()
表示 FilePicker 已被松开。

方法

Open()
打开 FilePicker，如同用户点击了它。

音频播放器（Player）

播放音频并控制手机振动的多媒体组件。多媒体 文件的名称在 Source 属性中指定，该属性可以在设计视图或 编程视图中设置。振动的时长在编程视图中以 毫秒（千分之一秒）为单位指定。

有关支持的音频格式，请参阅 Android Supported Media Formats。

对于较长的声音文件（例如歌曲），此组件最为合适；而 Sound 组件 对于较短的文件（例如音效）效率更高。

属性

IsPlaying
报告媒体是否正在播放。
Loop
如果为真，Player 会在播放时循环。在播放器正在播放时设置 Loop 会影响当前正在进行的播放。
PlayOnlyInForeground
如果为真（默认选项），Player 在离开当前屏幕时会暂停播放； 如果为假，则无论当前屏幕是否正在显示，Player 都会继续播放。
Source
设置音频来源。
Volume
将音量属性设置为 0 到 100 之间的数字。

事件

Completed()
表示媒体已播放到结尾
OtherPlayerStarted()
当另一个播放器开始播放时（且当前播放器正在播放或 已暂停，但未停止）发出此事件。

方法

Pause()
暂停播放媒体（如果正在播放）。
Start()
播放媒体。如果之前是暂停状态，则恢复播放。 如果之前是停止状态，则从头开始播放。
Stop()
停止播放媒体，并定位到歌曲开头。
Vibrate(milliseconds)
振动指定的毫秒数。

音效播放器（Sound）

播放声音文件，并可按编程视图中指定的毫秒数（千分之一秒） 选择性地振动的多媒体组件。要播放的声音 文件名可以在设计视图或编程视图中指定。

有关支持的声音文件格式，请参阅 Android Supported Media Formats。

此 Sound 组件最适合较短的声音文件（例如音效），而 Player 组件对于较长的声音（例如歌曲）效率更高。

属性

MinimumInterval
指定两次调用 Play 之间所需的最小间隔，单位为 毫秒。 一旦声音开始播放，在时间间隔过去之前，所有后续对 Play 的调用都将被忽略。
Source
声音文件的名称。只支持某些格式。 参见 http://developer.android.com/guide/appendix/media-formats.html。

事件

无

方法

Pause()
如果声音正在播放，则暂停播放。
Play()
播放声音。
Resume()
在暂停之后恢复播放声音。
Stop()
如果声音正在播放，则停止播放。
Vibrate(millisecs)
振动指定的毫秒数。

语音识别器（SpeechRecognizer）

使用 SpeechRecognizer 组件倾听用户说话，并利用设备的语音识别功能 把说的内容转换成文本。

属性

AvailableCountries
此设备上可用于 SpeechRecognizer 的国家/地区代码列表。这些国家/地区代码取自 所支持的 BCP-47 语言标记的 region 子标记（例如，从 en-US 得到 US）。如果 设备不支持语音识别，或该列表尚未填充，则返回空 列表。
AvailableLanguages
此设备上可用于 SpeechRecognizer 的语言列表。 语言以 BCP-47 语言标记的形式提供， 例如 en-US 和 es-MX。如果设备不支持语音识别，或该列表尚未 填充，则返回空列表。
Language
建议用于识别语音的语言。空字符串（默认值） 将使用系统的默认语言。

语言用 语言标记（language tag） 指定，可带可选的区域后缀，例如 en 或 es-MX。所支持的语言集合 因设备而异。

Result
返回识别器最后生成的文本。
UseLegacy
如果为真，则使用单独的对话框来识别语音（默认）。如果为假，则在 后台识别语音，并在识别词语的过程中接收更新。 AfterGettingText 可能会被多次调用，其中 partial 被设为 true。 当距最后一次说话已过去足够长时间，或调用了 StopListening 时， 将返回最后一个字符串，其中 partial 被设为 false，以表示它是 最终识别出的字符串，在再次开始识别之前不会提供更多数据。有关 部分语音识别的更多细节，请参阅 AfterGettingText。

事件

AfterGettingText(result,partial)
在 SpeechRecognizer 识别出语音后要引发的简单事件。如果 UseLegacy 为 true，则此事件只在识别的 最末尾发生一次。如果 UseLegacy 为 false， 则随着 SpeechRecognizer 逐步识别语音，此事件会运行多次 。此时，在识别出的语音 最终确定（例如用户停止说话）之前，partial 将为 true； 而一旦确定，partial 将为 false。
BeforeGettingText()
在调用 SpeechRecognizer 之后、其活动开始之前 要引发的简单事件。

方法

GetText()
要求用户说话，并把语音转换成文本。结果可用时发出 AfterGettingText 事件。
Stop()
在 SpeechRecognizer 无法自动停止的情况下，用于强制停止 倾听语音的函数。 仅当 UseLegacy 属性 设为 false 时此函数才有效。

语音合成器（TextToSpeech）

TextToSpeech 组件会朗读给定的文本。您可以设置音调 和语速。

您也可以通过提供语言代码来设置语言。这会改变词语的发音， 而不是实际所说的语言。例如，把 Language 设为法语 并朗读英语文本，听起来就像是有法语口音的人说英语。

您还可以通过提供 Country 代码来指定国家/地区。这可能会影响 发音。例如，英式英语（GBR）听起来会与美式英语（USA）不同。 并非每个国家/地区代码都会影响每种语言。

可用的语言和国家/地区取决于具体设备，可以用 AvailableLanguages 和 AvailableCountries 属性列出。

属性

AvailableCountries
此设备上可用于 TextToSpeech 的国家/地区代码列表。请查阅 Android 开发者文档中支持的语言一节，以了解这些缩写的含义。
AvailableLanguages
此设备上可用于 TextToSpeech 的语言列表。请查阅 Android 开发者文档中支持的语言一节，以了解这些缩写的含义。
Country
用于语音生成的国家/地区代码。这可能会影响发音。例如， 英式英语（GBR）听起来会与美式英语（USA）不同。并非每个国家/地区代码都会 影响每种语言。
Language
设置 TextToSpeech 的语言。这会改变词语的发音方式，而不是 实际所说的语言。例如，把语言设为法语并朗读 英语文本，听起来就像是有法语口音的人说英语。
Pitch
设置 TextToSpeech 的语音音调。

取值应在 0 到 2 之间，值越小合成语音的音调越低， 值越大音调越高。

默认值为 1.0，即正常音调。

Result
如果文本成功转换为 语音则返回 true，否则返回 false。
SpeechRate
设置 TextToSpeech 的语速。

取值应在 0 到 2 之间，值越小语速越慢， 值越大语速越快。

默认值为 1.0，即正常语速。

事件

AfterSpeaking(result)
消息朗读完后要引发的事件。如果消息朗读成功，result 将为 true，否则将为 false。
BeforeSpeaking()
调用 Speak 时、在朗读消息之前要引发的事件。

方法

Speak(message)
朗读给定的消息。
Stop()
停止当前任何朗读。

语言翻译器（Translator）

使用此组件在不同语言之间翻译单词和句子。此组件需要 访问互联网，因为它会向 MIT 的服务器请求翻译（该服务器 又会向一家商业翻译服务请求翻译）。 用两个字母的语言代码、以 source-target 的形式 指定源语言和目标语言。所以“en-es”会把 英语翻译为西班牙语，而“es-ru”会把西班牙语翻译为 俄语。如果省略源语言，服务会 尝试检测源语言。所以只提供“es”会 尝试检测源语言并将其翻译为西班牙语。

注意：翻译在后台异步进行。翻译完成后， 会触发 GotTranslation 事件。

属性

ApiKey
要使用的 API 密钥。App Inventor蔻丁工坊 会自动填入此 值。您无需更改它。

事件

GotTranslation(responseCode,translation)
表示请求已完成并已返回数据（翻译）的事件。

方法

RequestTranslation(languageToTranslateTo,textToTranslate)
通过提供要翻译成的目标语言（例如，'es' 表示西班牙语，'en' 表示 英语，或 'ru' 表示俄语）以及要翻译的单词或句子，此方法将请求 翻译。外部服务翻译完文本后， 将执行 GotTranslation 事件。

注意：Translator 会尝试检测源语言。您也可以把它前置 在语言翻译之前来指定，例如 es-ru 表示从西班牙语翻译到俄语。

视频播放器（VideoPlayer）

能够播放视频的多媒体组件。运行应用时，VideoPlayer 会在屏幕上显示为一个矩形。如果用户触摸该矩形，会出现控制条， 用于在视频中播放/暂停、快进和快退。应用也可以 通过调用 Start、Pause 和 SeekTo 方法来控制其行为。

视频文件应采用 3GPP（.3gp）或 MPEG-4（.mp4）格式。有关合法 格式的更多细节，请参阅 Android Supported Media Formats。

App Inventor 只允许小于 1 MB 的视频文件，并把应用的总大小限制为 5 MB，其中并非全部可用于媒体（视频、音频和声音）文件。如果您的媒体 文件过大，打包或安装应用时可能会出错，此时 应减少媒体文件的数量或大小。大多数视频编辑软件， 例如 Windows Movie Maker 和 Apple iMovie，都可以通过缩短视频 或把视频重新编码为更紧凑的格式来帮助您减小视频大小。

您也可以把媒体来源设为指向流式视频的 URL，但该 URL 必须 指向视频文件本身，而不是播放该视频的程序。

属性

FullScreen
设置视频是否应以全屏方式显示。
Height
指定组件的垂直高度，以像素为单位。
HeightPercent
以 Screen 的 Height 的百分比形式 指定 VideoPlayer 的垂直高度。
Left
指定组件左边缘相对于 AbsoluteArrangement 的位置。
Source
返回视频的“路径”。
Top
指定组件上边缘相对于 AbsoluteArrangement 的位置。
Visible
指定 VideoPlayer 是否在屏幕上可见。若 VideoPlayer 正在显示，值为 true； 若已隐藏，值为 false。
Volume
将音量属性设置为 0 到 100 之间的数字。小于 0 的值 将按 0 处理，大于 100 的值将按 100 处理。
Width
指定组件的水平宽度，以像素为单位。
WidthPercent
以 Screen 的 Width 的百分比形式 指定 VideoPlayer 的水平宽度。

事件

Completed()
表示视频已播放到结尾

方法

GetDuration()
返回视频时长，以毫秒为单位。
Pause()
暂停视频播放。可以调用 Start 方法从同一位置恢复播放。
SeekTo(ms)
定位到视频中请求的时间（以毫秒为单位）。如果视频处于暂停状态，所显示的帧不会因定位而更新。播放器只能跳到视频中的关键帧，因此定位到间隔很短的不同时间可能实际上不会移动到不同的帧。
Start()
播放由 Source 指定的媒体。
Stop()
重置到视频开头，如果视频正在播放则暂停它。
