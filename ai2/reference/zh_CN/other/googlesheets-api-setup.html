注意：如果您只需要从 Google Sheets 文档中读取，而不需要编辑或写入数据，就可以跳过创建服务账号的步骤。唯一的要求是把该 Google Sheets 文档设置为“知道链接的任何人”都可以阅读。

创建服务账号

在本教程中，我们将创建一个服务账号（Service Account），这是一种专门用来与特定软件或服务交互的用户账号。在这里，这个特定的软件就是 Google Sheets API。之后，您可以在用 App Inventor 制作的其他应用中重复使用这个服务账号。

1. 创建 Google 开发者账号

使用 Google Sheets API 的第一步是创建一个 Google 开发者账号。Google 开发者账号就是启用了开发者工具的 Google 账号；所以如果您还没有账号，请先访问 https://www.google.com 创建一个 Google 账号。创建完成后，访问 https://developers.google.com 并登录您想使用的 Google 账号。这个账号不必是拥有您要使用的 Google Sheets 文档的那个 Google 账号。

2. 创建 Google 开发者项目

下一步是创建一个开发项目。登录 Google 开发者账号后，访问 https://console.developers.google.com/。如果这是您第一次使用 Google 开发者账号，系统会提示您同意服务条款。勾选该复选框并继续。

接下来会进入开发者控制台首页。如果您此前还没创建过项目，可以选择 [CREATE PROJECT] 来创建您的第一个项目。

如果您使用已有的开发者账号并且已经有项目，会进入某个项目的首页。要创建新项目，请点击网页顶部的下拉菜单。

在弹出的菜单顶部选择 NEW PROJECT。

在创建页面上为项目起一个名称。在本教程中，我们把它命名为“App Inventor”。这里不需要指定组织，因此保持为 No organization。

点击“Create”完成项目创建。

3. 启用 Google Sheets API

下一步是为您的项目启用 Google Sheets API。点击 APIs & Services 旁边的“+ Enable APIs and Services”按钮。

在搜索栏中输入“Google Sheets API”，选中出现的搜索结果，然后点击 API Library 中的 Enable 按钮。

4. 创建服务账号

现在我们已经为这个项目启用了 Google Sheets API，接下来要创建一个服务账号。简单来说，服务账号看起来很像一个 Google 邮箱账号。为 Google Sheets API 点击“Enable”按钮后，您会被带到项目中 Google Sheets API 的 Overview（概览）标签页。点击屏幕右侧的“Create Credentials”，即可开始创建服务账号。

在下一页会出现一个引导向导，询问您正在制作哪类项目。在“Which API are you using?”下方的第一个下拉菜单中，选择 Google Sheets API。

选择之后，下面会出现一个后续问题。在“Where will you be calling the API from?”下选择 Other UI。最后，在访问哪些数据（what data will you be accessing）下选择 Application Data。

填完上述信息后，点击标有“What credentials do I need?”的蓝色按钮。这将进入创建凭据的第二部分。在这一部分您可以自定义服务账号，界面应与下图一致。

服务账号的名称并不重要。在本教程中，我把它命名为“example-service”。然后把角色设为 Selecting Project > Editor，这应当能为该服务账号提供足够的权限。请务必保存标有 Service Account ID 的框中完整的文本。您会发现它看起来很像一个电子邮件地址。请把这个 Service Account ID 复制到某个地方保存，以便后面使用。

请确认 Key Type 下像上图那样选中了“JSON”，然后再点击“Continue”。这会下载一个名为“AppInventor-####.json”的 JSON 文件。

使用 Google Sheets API 组件时，我们需要上传这个 JSON 文件才能正常工作。请务必妥善保管这个 JSON 文件！

关联 Google Sheets 文档

现在服务账号已经创建好了，接下来要让这个服务账号能够访问我们将要写入或读取的 Google Sheets 文件。

1. 创建 Google Sheets 文档

第一步（如果还没有的话）是创建一个 Google Sheets 文档。文档名称可以任意。如果您已经有想用的 Google Sheets 文件，就直接进入 Google 云端硬盘，导航到您想创建文档的位置，然后点击“New”（新建）并选择“New Sheet”（新建表格）。

2. 共享 Google Sheets 文档

创建好要使用的 Google Sheets 文件后，只需把该文件共享给之前保存的服务账号邮箱即可。这样就能为服务账号提供您所需的权限。您可以通过在 Viewer（查看者）与 Editor（编辑者）之间切换权限，来指定该服务账号是只能读取数据，还是可以读写数据。

3. 记录相关信息

最后，为了正确访问该文件，您需要记录关于这个 Google Sheets 文档的几项信息。这部分说明也可以作为日后查找这些信息的参考。

关于这些术语的更多内容，请参阅此处。

电子表格 ID

电子表格 ID 可以在 Google Sheets 文档的 URL 中找到。Google Sheets 文档的 URL 通常形如：

https://docs.google.com/spreadsheets/d/<Spreadsheet ID>/edit#gid=<Grid ID>

电子表格 ID 就是该 Google Sheets 文件的 ID。

工作表名称

一个电子表格中包含若干单独的工作表，每个工作表都有各自的标题和 ID 编号。在该组件中，工作表的标题称为 sheetName。

一个电子表格文档可以有多个工作表。默认情况下，新建 Google Sheets 文档时，表格中只有一个名为“Sheet1”的工作表。您可以在屏幕左下角的标签页中看到它，如下所示：

按“+”符号可以为文档添加新的工作表。这样会在 Sheet1 旁边新建一个标签页，名为 Sheet2。

Google Sheets 组件中的每个块都会要求您指定要读取或编辑的工作表标题（即“Sheet Name”）。例如，如果我想编辑 Sheet2 上的值，就要在 sheetName 插槽中填入文本“Sheet2”。

此外，您还可以在标签页上单击右键并点击 rename（重命名），把工作表改成任意名称。注意，这样做之后，项目中对应的工作表名称也需要一并修改才能匹配。

网格 ID

与工作表名称类似，网格 ID 也用来指明您想编辑哪个工作表。但与工作表名称不同的是，网格 ID 无法由用户自定义。某些块要求提供网格 ID 而不是工作表名称。要找到网格 ID，请点击标签页切换到您要引用的工作表。在 URL 的末尾应当可以看到“gid=”后跟一个数字。

https://docs.google.com/spreadsheets/d/<Spreadsheet ID>/edit#gid=<Grid ID>

调试提示

Unable to resolve host "oauth2.googleapis.com"

如果出现这条错误信息，请再检查一下设备的网络连接。它表明 Android 网络子系统无法解析该主机名，因此无法与 DNS 通信。

Attempt to invoke virtual method … on a null object reference.

如果出现这条错误信息，请再检查一下您是否在设计器属性中关联了凭据。如果设计器属性显示为下图中的“None…”，请点击该框，并选择您在创建服务账号步骤中得到的 .json 文件。

Unable to parse range: ______

如果出现这条错误信息，可能是您提供的数据范围有问题。这可能意味着您提供的 sheetName 实际上并不存在，或者您提供的引用不是有效的 A1 表示法。要了解 A1 表示法的更多内容，请参阅：https://developers.google.com/sheets/api/guides/concepts#a1_notation
