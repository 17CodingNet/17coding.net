创建自定义微数据库（TinyWebDB）服务

TinyWebDB（微数据库）是 App Inventor 的一个组件，可以让您把数据持久地保存在网络数据库中。由于数据保存在网络上，而不是某一台手机里，因此 TinyWebDB 可以用来在手机和应用之间通信（例如多人游戏）。

默认情况下，TinyWebDB 组件把数据保存在 App Inventor 提供的测试服务上：http://tinywebdb.appinventor.mit.edu/ 。该服务便于测试，但它由所有 App Inventor 用户共用，并且最多只能保存 1000 条记录。如果您使用它，您的数据最终会被覆盖。

对于您编写的大多数应用，您会希望创建一个自定义网络服务，不与其他 App Inventor 应用和程序员共用。要做到这一点，您不必是程序员——只要按下面的说明操作，几分钟内就能拥有自己的服务。

要创建自己的网络服务，请按以下步骤操作：

  • 从 http://code.google.com/appengine/ 下载适用于 Python 的 App Engine。安装后，点击 GoogleAppEngineLauncher 的图标运行它。
  • 下载这个示例代码。这是一个 zip 文件，其中包含您自定义 TinyWebDB 网络服务的源代码
  • 解压下载的 zip 文件，会得到一个名为 customtinywebdb 的文件夹。如果需要，您可以给它改名。
  • 在 GoogleAppEngineLauncher 中，选择 File 菜单 中的 Add Existing Application。浏览并设置 Path，指向您刚解压出来的 customtinywebdb 文件夹。然后点击 Run 按钮。这样就会启动一个在本机运行的测试网络服务。
  • 您可以打开浏览器，在地址栏输入“localhost:8080”，以此来测试这个服务。您会看到该网络服务的网页界面。这个服务的最终目的是与用 App Inventor 创建的移动应用通信，不过它也提供了网页界面，方便程序员调试。您可以手动调用 get 和 store 操作、查看已有的记录，也可以删除单条记录
  • 您的应用此时还不在网络上，因此 App Inventor 应用还访问不到它。要把它部署到网上，需要把它上传到 Google 的 App Engine 服务器。
    • 在 GoogleAppEngineLauncher 中，选择 Dashboard。输入您的 Google 账号信息，就会进入 App Engine 控制台。
    • 选择 Create an Application。您需要指定一个全局唯一的 Application Identifier（应用标识符）。请记住这个标识符，后面还会用到。为应用起个名字，然后点击 Create Application 提交。如果标识符是唯一的，您就在 Google 服务器上拥有了一个新的空应用。
    • 在本地电脑上打开文本编辑器，打开您解压出来的 customtinywebdb 文件夹中的 app.yaml 文件。修改第一行，让其中的 application 与您在 Google 上设置的 application identifier 一致。
    • 在 GoogleAppEngineLauncher 中，选择 Deploy，然后按提示完成应用的部署。
  • 测试一下您的应用是否已经在网上运行：在浏览器中输入 myapp.appspot.com，只需把其中的“myapp”换成您的应用标识符。这个应用看起来应该和您在本地测试服务器上运行时一样，只不过现在它在网络上，您可以从 App Inventor 应用访问它了。 您的 App Inventor 应用可以用这个新服务来保存和读取数据。只需按以下步骤操作：

把一个 TinyWebDB 组件拖入设计视图。 把 ServiceURL（服务地址）属性从默认的 http://tinywebdb.appinventor.mit.edu/ 改为您的网络服务地址。 所有 StoreValue 操作（代码块）都会把数据保存到您的服务上，所有 GetValue 操作都会从您的服务中读取数据。
