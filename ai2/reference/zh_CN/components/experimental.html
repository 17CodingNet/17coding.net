聊天机器人（ChatBot）

ChatBot 组件是一个用于与 AI 聊天机器人交谈的非可见组件。 此版本使用 MIT 运营的代理服务器，该代理再使用 ChatGPT 生成式大语言模型。

属性

ApiKey
用于 ChatGPT 的 ApiKey，由用户提供。如果提供了它，我们将使用它，而不是 聊天代理服务中内置的 API 密钥。

注意：我们不把它作为设计视图属性（DesignerProperty）提供，而应使用 块来保存它，最好使用 “Obfuscated Text” 块，以便对打包应用中的密钥 提供一定程度的保护（并非完全的保护）。

Model
设置要使用的模型名称。当前支持的模型列表请见 https://appinv.us/chatbot。留空将使用由服务提供方设定的默认模型
Provider
设置要使用的提供方名称。当前支持的提供方列表请见 https://appinv.us/chatbot。
ServiceURL
设置 ChatBot 服务 URL。取值为 “DEFAULT” 表示将使用 MIT 服务器。
System
提供给 ChatGPT 的 “System” 值，用于设定对话的语气。例如：“You are a funny person.”
Token
要使用的 MIT 访问令牌。App Inventor蔻丁工坊 会自动填入该值， 您应当不需要修改它。

事件

ErrorOccurred(responseCode,responseText)
处理过程中发生错误时会运行 ErrorOccurred 事件，例如您的 用量超出配额，或者 ChatGPT、PaLM 报告了其他错误。 最新信息请见 https://appinv.us/chatbot。
GotModels(models)
获取到模型列表时触发的事件。
GotProviders(providers)
获取到提供方列表时触发的事件。
GotResponse(responseText)
表示请求已完成并返回数据（ChatBot 的输出）的事件。
GotResponseWithImage(responseText,fileName)
表示我们已经收到聊天机器人代理返回的响应，其中 包含一张图像，可能还附带与之配套的文字。

方法

Converse(question)
向聊天机器人提一个问题。连续调用会记住本次对话中之前的信息。使用 “ResetConversation” 函数可重置并开始新的对话。
ConverseWithImage(question,source)
使用图像向聊天机器人提一个问题。连续调用会记住本次对话中之前的信息。使用 “ResetConversation” 函数可重置并开始新的对话。
CreateImage(description)
创建一张图像。注意：目前仅支持 Gemini。不要指定模型，这样才能取用最新的可用模型。
GetModels()
获取可用模型的列表。
GetProviders()
获取可用提供方的列表。
ResetConversation()
重置当前对话，聊天机器人在之后的回复中会忘记以往的任何对话。

Firebase 数据库（FirebaseDB）

Firebase 组件与一个 Web 服务通信，以保存和检索信息。 该组件提供了一些方法，可以把值保存到某个标签（tag）下， 以及取出与该标签关联的值。它还带有一个监听器， 在已保存的值发生变化时触发事件。

附加信息

属性

DeveloperBucket
DeveloperBucket 的取值器。
FirebaseToken
FirebaseToken 的取值器。
FirebaseURL
指定 Firebase 的 URL。

当前默认值是我私有的 Firebase URL，但在 App Inventor Candle 计划启用之后，这个默认值终将改变。

Persist
若为 true，变量在离线且应用退出时会保留其值。下次应用联网运行时， 这些值会被上传到 Firebase。这对于需要在断开网络时收集数据的应用很有用。 注意：AppendValue 和 RemoveFirst 在离线时无法正常工作，它们需要网络连接。

注意：如果您在任意屏幕的任意 Firebase 组件上设置了 Persist，它会让所有屏幕上的所有 Firebase 组件都变为持久化。这是底层 Firebase 库的限制。另外请注意，如果您想把 persist 设为 true，应当在连接 AI 伴侣进行增量开发之前就设置好。
ProjectBucket
ProjectBucket 的取值器。

事件

DataChanged(tag,value)
表示 Firebase 中的数据已发生变化。 触发一个事件，携带被更新过的标签和值。
FirebaseError(message)
表示与 Firebase 的通信发出了错误信号。
FirstRemoved(value)
由 “RemoveFirst” 函数触发的事件。参数 “value” 是原本位于列表首位的对象，现在它已被移除。
GotValue(tag,value)
表示 GetValue 请求已成功。
TagList(value)
收到已知标签列表时触发的事件。与 “GetTagList” 函数配合使用。

方法

AppendValue(tag,valueToAdd)
以原子方式把一个值追加到列表末尾。如果两台设备同时使用该函数，两个值都会被追加，不会丢失数据。
ClearTag(tag)
请求 Firebase 忘记（删除或设为 “null”）给定的标签。
GetTagList()
获取本应用的标签列表。完成后会触发一个 “TagList” 事件，携带已知标签的列表。
GetValue(tag,valueIfTagNotThere)
GetValue 请求 Firebase 取出存储在给定标签下的值。 如果该标签下没有存储值，它会把 valueIfTagNotThere 传给 GotValue。
RemoveFirst(tag)
返回列表的第一个元素并以原子方式将其移除。如果两台设备同时使用该函数，一台会得到第一个元素，另一台会得到第二个元素；若没有可用元素则报错。当元素可用时，会触发 “FirstRemoved” 事件。
StoreValue(tag,valueToStore)
请求 Firebase 把给定的值存储到给定的标签下。
Unauthenticate()
取消与 Firebase 的身份验证。

Firebase 会把凭据记录在 shared_prefs 的缓存中。 只要这些凭据有效，它就会一直复用。考虑到 我们获取的 FirebaseToken 具有很长的有效期，这实际上 会是永久有效的。shared_prefs 在应用更新后仍然存在， 并且取决于设备上备份的配置方式，它甚至可能在应用卸载并重新安装后仍然存在。

通常这不成问题，但如果我们更换了所使用的凭据， 例如应用作者从一个 Firebase 账号切换到另一个，或者 使自己的 firebase.secret 失效，那么这份缓存的凭据 就是无效的，却会继续被使用，从而导致错误。

此函数让我们可以取消身份验证，从而丢弃缓存的 凭据。下次需要进行身份验证时，我们会使用当前的 FirebaseToken 获取新的凭据。

作图机器人（ImageBot）

ImageBot 是一个非可见组件，它使用 DALL-E 2 来创建和编辑图像。您必须 在块中设置其 ApiKey 属性，为本组件提供您自己的 OpenAI API 密钥。

属性

ApiKey
指定用于向 ImageBot 进行身份验证的 ApiKey。
InvertMask
指定用于编辑的蒙版是否应当反转其 alpha 通道。
Size
指定生成图像的尺寸。可以是 256、512 或 1024 之一。
Token
要使用的 MIT 访问令牌。App Inventor蔻丁工坊 会自动填入该值， 您应当不需要修改它。

事件

ErrorOccurred(responseCode,responseText)
处理过程中发生错误时会运行 ErrorOccurred 事件，例如您 忘记提供 API 密钥，或者服务器过载。
ImageCreated(fileName)
ImageBot 成功创建一张图像时会运行 ImageCreated 事件。
ImageEdited(fileName)
ImageBot 成功编辑一张图像时会运行 ImageCreated 事件。

方法

CreateImage(description)
使用给定的描述创建一张图像。
EditImageWithMask(imageSource,maskSource,prompt)
使用给定的描述编辑 imageSource。图像的可编辑区域应当 由 maskSource 标示。这些来源可以是 Canvas、Image，或 表示文件路径的字符串。
